ANN - I

From the perceptron to backprop

One neuron → a layer → a network. We follow one small network (2-2-1) all the way through in numbers: predict with the forward pass, measure the loss, compute gradients backwards with backprop, then update.

2One neuron (the perceptron)

WHAT WE WANT TO KNOW

What exactly does a single neuron compute?

TERMS IN THIS SECTION

w, b
weight and bias. The numbers multiplied with the inputs and added to the sum.
z
The sum before the activation.
σ
sigma, the sigmoid. Squashes z into 0–1: σ(z) = 1 / (1 + e⁻ᶻ).
perceptron
A one-neuron classifier. The original uses a step function.
  • w how much each input matters
  • b shifts the threshold
  • z the sum
  • σ activation
  • ŷ output

WORKED EXAMPLE: x = (1, 2), w = (0.5, −0.25), b = 0.5

→ Meaning. With a step function, z > 0 gives 1 ("yes"). With a sigmoid it reads "62% likely yes".

THINGS TO TRY

  1. Make w₂ large: x₂ now decides the result. Line width = |w|, blue = positive, red = negative.
  2. Switch step ↔ sigmoid: step jumps between 0 and 1; sigmoid joins them smoothly (so it has a derivative).

One line to remember. A neuron multiplies and adds (z = w·x + b), then applies an activation (ŷ = σ(z)).

4Forward propagation: computing forwards

WHAT WE WANT TO KNOW

Wire neurons up as 2-2-1: in what order does the prediction ŷ come out, and what shape is each step?

TERMS IN THIS SECTION

2-2-1
2 inputs → 2 hidden neurons → 1 output.
h
The hidden layer's output: the layer that is neither input nor output.
W₁, b₁
Layer 1's weight matrix and bias. One row of W = one neuron.

In words: each layer does "multiply, add, σ" once. One matrix product does the work of several neurons at once.

THE NUMBERS IN THE EXAMPLE (same as the figure)

→ Meaning. The result is ŷ = 0.595: only 59% sure of the right answer, 1. Use the buttons below to go one step at a time.

One line to remember. Forward = at each layer z = Wa + b, a = σ(z). Shapes: (outputs × inputs) · (inputs × 1).

5Error, loss and cost

WHAT WE WANT TO KNOW

How do the three names for "how wrong" differ?

TERMS IN THIS SECTION

BCE
binary cross-entropy. The loss for 0/1 classification; the same cross-entropy as chapter 1, section 7.
J
The cost: the mean loss over all samples.

In words: if the answer is 1 the loss is −ln ŷ, if it is 0 it is −ln(1 − ŷ). The smaller the probability given to the right answer, the faster the penalty grows.

WORKED EXAMPLE: ŷ = 0.5947 from section 4, y = 1

→ Meaning. Training lowers the cost J. Gradient descent (chapter 2) walks down J's slope.
answer y

One line to remember. Error = the difference (with a sign), loss = one sample's penalty, cost = the mean over all. Training lowers the cost.

6Backpropagation: gradients, working backwards

WHAT WE WANT TO KNOW

Which way, and how much, should each of the six weights move to lower the loss? Apply the chain rule (chapter 2, section 4) layer by layer, from the output back towards the input.

TERMS IN THIS SECTION

δ
delta, ∂L/∂z: how much the loss changes when this neuron's sum z changes a little.
⊙
Multiply matching positions (element-wise).
σ′
The slope of the sigmoid = σ(1 − σ) = h(1 − h).
  • δ the signal flowing backwards
  • W₂ᵀδ₂ back through the same weights
  • σ′ times the activation's slope (chain rule)
  • δ · inputᵀ = that weight's gradient

RESULTS FOR THE EXAMPLE

→ Meaning. Raise the weights whose gradient is negative and lower those whose gradient is positive, and the loss drops. The layer nearer the input has smaller gradients (one more factor σ′ ≤ 0.25: chapter 2, section 9).

One line to remember. Backprop sends the output's δ back through the weights, multiplying by σ′ on the way. A weight's gradient = δ × the input that came through that weight.

8The same calculation in PyTorch

WHAT WE WANT TO KNOW

How many lines does PyTorch need for the hand calculation in sections 4–7?

TERMS IN THIS SECTION

nn.Linear(2, 2)
One z = Wx + b layer (W is 2×2).
autograd
automatic differentiation. The single line loss.backward() does all of section 6's backprop.
SGD
stochastic gradient descent. The optimizer that does W ← W − η·gradient.
import torch
net = torch.nn.Sequential(
    torch.nn.Linear(2, 2), torch.nn.Sigmoid(),   # W₁, b₁ → h
    torch.nn.Linear(2, 1), torch.nn.Sigmoid())   # W₂, b₂ → ŷ
with torch.no_grad():                            # put in the numbers from section 4
    net[0].weight[:] = torch.tensor([[0.4, -0.6], [0.7, 0.2]])
    net[0].bias[:]   = torch.tensor([0.1, -0.3])
    net[2].weight[:] = torch.tensor([[0.9, -0.5]])
    net[2].bias[:]   = torch.tensor([0.2])
x, y = torch.tensor([[1.0, 0.5]]), torch.tensor([[1.0]])
yhat = net(x)                                    # forward (section 4)
loss = torch.nn.BCELoss()(yhat, y)               # loss (section 5)
loss.backward()                                  # backprop (section 6)
print(round(yhat.item(), 4), round(loss.item(), 4))
print(net[2].weight.grad)
print(net[0].weight.grad)
opt = torch.optim.SGD(net.parameters(), lr=0.5)
opt.step()                                       # update (section 7)
print(round(net(x).item(), 4))

The output matches the hand calculation: ŷ = 0.5947, L = 0.520, the gradients of section 6, and ŷ = 0.681 after one step.

One line to remember. In PyTorch: net(x) = forward, loss.backward() = backprop, opt.step() = update.
