DL-EDU · CHAPTER 13

RNN

Sequences, GRU, LSTM

A network that reads ordered data (time series, text, sound) one step at a time and carries a hidden state, a "summary so far", from step to step. GRUs and LSTMs control that memory with gates, and the chapter ends with the limit of forgetting the distant past (the starting point for attention in chapter 14).

1Why sequences need their own models

WHAT WE WANT TO KNOW

Did the networks so far care about the order of their inputs? What if the order changes?

Sequence dataOne stepWhat the order does
Time series (prices, sensors)a value at one momenttrend, cycles
Texta character or word"dog bites man" ≠ "man bites dog"
Sound, videoa short slice, a framemotion, speech

An FFN has a fixed number of inputs and learns each input position separately. For data whose length varies and where "what came before" matters, a structure that reads one step at a time and passes memory along fits better.

One line to remember. In a sequence the information is in the order more than in the values, and lengths vary.

2How RNNs work: the hidden state carries over

WHAT WE WANT TO KNOW

How can "everything read so far" be carried around in a few numbers?

TERMS IN THIS SECTION

RNN
recurrent neural network. A network that feeds part of its output (h) back in as input at the next step.
hidden state h_t
A summary of everything read up to step t.
  • x_t input at this step
  • h_{t−1} the previous summary
  • h_t the new summary

WORKED EXAMPLE: a one-number RNN, w_x = 0.5, w_h = 0.8, b = 0, inputs 1, 0, 0, 1, h₀ = 0

→ Meaning. While the input is 0, h carries the first 1 along, fading 0.46 → 0.35 → 0.28. When the last 1 arrives it adds on top of the remaining 0.28.

One line to remember. RNN = the same weights, one step at a time: h_t = tanh(W_x x_t + W_h h_{t−1}). h is the memory.

4Predicting alternating sequences; extrapolating a sine wave

WHAT WE WANT TO KNOW

Can an RNN remember a pattern to predict the next value, and keep drawing into a future it never saw?

RESULT 1: the next value of the period-3 pattern 1, 0, 0, 1, 0, 0, … (PyTorch)

→ Meaning. After a 0 the next value can be 0 or 1: looking only at the previous value gets just 2/3 right. The RNN keeps "how many 0s so far" in h and gets every one.
hidden

RESULT 2: trained on 200 steps of sin(0.3t) → the next 150 steps from its own predictions only, RMSE

→ Meaning. With 2 or more units it keeps the wave going, but small errors pile up and the phase slips a little as time goes on. Generating by feeding predictions back accumulates error.

One line to remember. An RNN continues a pattern through its memory h. Generating from its own predictions piles up error.

5Hidden states and embeddings

WHAT WE WANT TO KNOW

Characters and words are not numbers, so how do they go in? What does an LSTM learn by predicting the next character?

  • E a learned table of 8-number vectors, one per character (nn.Embedding)
  • W a matrix that turns h_t into one score per character
  • T temperature: high = more even, low = only the most likely

WORKED EXAMPLE: three next characters with scores (2, 1, 0), at T = 0.5, 1, 2

Divide the scores by T, then apply softmax. With T = 0.5 the scores become (4, 2, 0), so the gaps double.

→ Meaning. With a low T the top character takes 87% and the text tends to repeat itself; with a high T even the third character gets 19%, so the text is new but has wrong characters in it. The text in the table below was made with T = 0.8.
Text generated during training (trained on 1,848 characters of Cicero's text, the source of Lorem ipsum; temperature 0.8)
StepsLossText generated from "l"

At first any characters; after 100 steps new Latin-looking words; after 300 the words are nearly right; after 1,500 it recites the original word for word (the text is only 1,848 characters, so it overfits, chapter 5). On the embedding map the vowels (a, e, i, o, u) gather on one side: nobody told it about vowels, but they play similar roles when predicting the next character.

One line to remember. Embedding = a table that turns characters or words into learned vectors. Predicting the next character alone teaches spelling and words.

6GRU and LSTM: gates that control memory

WHAT WE WANT TO KNOW

How can the network decide for itself what to forget and what to keep?

  • f forget: how much old memory to keep (0 to 1)
  • i input: how much new to write (0 to 1)
  • o output: how much memory to show (0 to 1)
  • g the new candidate (−1 to 1)
  • c cell state (long memory)
  • [h, x] the two vectors joined end to end
  • ⊙ element-by-element product
  • W_f, W_i, W_o, W_g separate learned weights for each gate

WORKED EXAMPLE: one step of a one-number LSTM, previous memory c_{t−1} = 2.0

Say the gates and the candidate have already been computed with the formulas above: f = 0.9, i = 0.5, g = −0.6, o = 0.8. First update the memory c.

Squash that memory with tanh and show as much as the output gate allows.

c is carried only by multiplying and adding, so going one step back along c multiplies the gradient by f. Over 50 steps, f is multiplied 50 times.

→ Meaning. 90% of the old memory 2.0 is kept and half of the new candidate −0.6 is added. With f near 1, 60% of the gradient is still there after 50 steps. Section 2's RNN shrinks it at every step through tanh and W_h (section 7).
Input 8, hidden 64Gate setsParametersCharacter
RNN14,736Simplest; hard to remember long
GRU3 (z, r, h̃)14,208One h, no c; z decides "keep or replace"
LSTM4 (i, f, g, o)18,944A separate c is the long-memory channel

One line to remember. The LSTM's c_t = f·c_{t−1} + i·g: with forget near 1, memory and gradients last long. The GRU is a lighter relative.

7Limits of RNNs → on to attention

WHAT WE WANT TO KNOW

How much does an input 100 steps back affect the last output? Can the network actually remember something far away?

RESULT 1: hidden 32, 100 steps, before training (PyTorch autograd), gradient of an input 50 steps back

→ Meaning. About ×0.5 is multiplied in at every step, so the gradient shrinks exponentially with distance (the same reason as chapter 12, section 3). Starting the forget gate near 1 (bias 3 → σ(3) = 0.95) lets the gradient come back through c almost intact.

RESULT 2: recall the first bit of a random 0/1 sequence T steps later, hidden 16, 2,000 training steps, successes out of 3 seeds

→ Meaning. An LSTM does not remember long by itself: it depends on the initial values and the training time. At 80 steps all three are at guessing level with this much training. On top of that an RNN computes one step after another, so long texts are slow. Chapter 14's attention looks at every step at once, directly, regardless of distance.

One line to remember. An RNN's memory fades as it is multiplied step by step. Gates slow the fading but cannot remove it → attention.
