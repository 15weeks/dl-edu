Gradient descent

미분, model이 배우는 방법

model이 "배운다" = loss(틀린 정도)가 줄어드는 쪽으로 숫자를 조금씩 고친다. 어느 쪽인지는 미분(기울기)이 알려 준다. 이 장은 글보다 그림으로 간다. 그림을 움직여 보고, 회색 상자의 숫자로 확인한다.

1model이 "배운다"는 것

알고 싶은 것

점 4개를 가장 잘 지나는 직선 ŷ = w·x를 computer는 어떻게 찾나?

이 절에 나오는 약자

parameter
(파라미터). model이 고쳐 가며 배우는 숫자. 여기서는 w 하나.
ŷ
(y hat). model의 예측. y는 정답.
loss, L
(손실). 틀린 정도를 숫자 하나로. 작을수록 좋다.
MSE
mean squared error (평균 제곱 오차). 오차를 제곱해서 평균 낸 loss.
  • w 고칠 숫자
  • w·xᵢ 예측 ŷ
  • yᵢ 정답
  • n 점의 수 (4)

말로: 예측과 정답의 차이를 제곱해서 평균 낸다.

예제: w = 1일 때 loss, 그리고 한 걸음

→ 뜻. 기울기 −14.85는 "w를 키우면 loss가 준다"는 뜻. 한 걸음에 7.38 → 2.25. 10걸음이면 w = 1.99 (가장 좋은 값).

해 볼 것

  1. 한 걸음을 여러 번: 왼쪽 직선이 점에 붙고, 오른쪽 공이 바닥으로 간다.
  2. w slider를 3으로: 빨간 오차가 반대로 생기고 기울기가 양수가 된다.

기억할 한 줄. 배운다 = 예측 → loss → 기울기 → 고치기를 반복해 loss를 줄인다.

2미분: 기울기 그래프

알고 싶은 것

곡선의 모든 점에서 기울기를 재면 무엇이 나오나?

이 절에 나오는 약자

f′(x)
derivative (미분, 도함수). x에서의 기울기. "f prime"이라 읽는다.
h
x를 바꾸는 아주 작은 양.
  • f′(x) 기울기 = 조금 바꿨을 때의 변화율
  • n 지수가 앞으로 나오고 하나 준다

예: x² → 2x, x³ → 3x², x³ − 3x → 3x² − 3 (더한 것은 따로따로 미분).

예제: x³의 x = 2에서 기울기

→ 뜻. x = 2에서 x를 조금 늘리면 x³은 그 12배만큼 는다. 규칙으로 구한 값과 직접 잰 값이 같다.

해 볼 것

  1. 기울기 그래프 그리기: 위의 접선이 움직이며 아래 그래프를 그린다.
  2. x³ − 3x에서 x = ±1: 접선이 수평, 아래 그래프는 0.
f(x)

기억할 한 줄. 미분 = 곡선의 각 점의 기울기를 모은 새 그래프. 다항식은 xⁿ → n·xⁿ⁻¹.

3미분으로 바닥 찾기

알고 싶은 것

loss가 가장 작은 곳(바닥)은 미분으로 어떻게 알아보나?

  • 초록 f′ < 0, 내리막
  • 빨강 f′ > 0, 오르막
  • 내리막 → 오르막으로 바뀌는 곳 = 바닥

예제: f(x) = x² − 4x + 5의 바닥

→ 뜻. x = 2가 바닥: 양옆 f(1.9) = f(2.1) = 1.01로 더 높다. 하지만 식이 복잡하면 f′ = 0을 손으로 풀 수 없다. 그래서 다음 절의 "조금씩 내려가기"를 쓴다.

해 볼 것

  1. x³ − 3x: f′ = 0인 곳이 두 개. 하나는 바닥, 하나는 꼭대기.
  2. x⁴/4 − x²: 바닥이 두 개다. 7절에서 다시 나온다.
f(x)

기억할 한 줄. 바닥에서는 기울기가 0이고, 그 왼쪽은 내리막(−), 오른쪽은 오르막(+)이다.

4product rule과 chain rule

알고 싶은 것

곱한 함수, 함수 안의 함수는 어떻게 미분하나? 신경망은 함수가 여러 겹 쌓인 것이라 chain rule이 핵심이다.

곱의 미분 (product rule)

말로: 직사각형 u × v가 커질 때 늘어난 넓이 = 오른쪽 띠(v·Δu) + 위쪽 띠(u·Δv). 모서리는 너무 작아 사라진다.

예제: y = x²·(x + 1), x = 2

→ 뜻. 펼쳐서 y = x³ + x²로 미분해도 3·4 + 2·2 = 16. 같다.

함수 안의 함수 (chain rule)

말로: x가 조금 변하면 u는 du/dx배, y는 다시 dy/du배 변한다. 배율끼리 곱한다.

예제: y = (3x + 1)², x = 1 (u = 3x + 1 = 4)

→ 뜻. x가 0.1 늘면 u는 0.3, y는 약 8 × 0.3 = 2.4 는다. 아래 자 세 개가 이것을 보여 준다. 3장의 backprop은 이 곱셈을 층마다 한다.

그림 읽는 법

  • 자 세 개의 눈금 간격이 같다. 색칠한 칸 = 작은 변화. 아래로 갈수록 칸이 몇 배로 넓어진다.

기억할 한 줄. 겹친 함수의 미분 = 각 겹의 배율을 곱한다 (chain rule).

5gradient descent: 기울기 반대로 한 걸음

알고 싶은 것

f′ = 0을 풀 수 없을 때, 바닥은 어떻게 찾나? 기울기를 보고 조금씩 내려간다.

이 절에 나오는 약자

GD
gradient descent (경사 하강법). 기울기 반대쪽으로 조금씩 가기.
η, LR
eta(에타), learning rate (학습률). 한 걸음의 크기를 정하는 숫자.
  • x 지금 위치
  • η 걸음 크기
  • f′(x) 지금 기울기
  • − 기울기의 반대쪽으로

예제: f(x) = (x − 2)² + 1, x = 5, η = 0.1

→ 뜻. 기울기가 양수 → 왼쪽으로. 바닥에 가까워지면 기울기가 작아져 걸음도 저절로 작아진다: 4.4, 3.92, 3.54, 3.23, …

해 볼 것

  1. 한 걸음을 여러 번: 걸음이 점점 짧아진다 (기울기가 작아지니까).
  2. 공을 바닥 왼쪽(x = 0)으로 끌어 놓기: 기울기가 음수 → 오른쪽으로 간다.

기억할 한 줄. x ← x − η·f′(x). 기울기가 크면 크게, 작으면 작게 걷는다.

6learning rate: 걸음 크기

알고 싶은 것

η가 너무 작거나 너무 크면 어떻게 되나?

말로: 바닥(x = 2)까지 거리에 매 걸음 (1 − 2η)를 곱한다. 이 배율 하나로 네 가지가 갈린다.

η배율 1 − 2η무슨 일10걸음 뒤 x
0.020.96거의 안 줄어든다: 느리다3.99
0.20.6곧게 줄어든다: 알맞다2.02
0.9−0.8부호가 바뀌며 줄어든다: 지그재그2.32
1.05−1.1점점 커진다: 발산9.78

점점 줄어드는 learning rate (dynamic learning rate)

→ 뜻. 처음엔 크게 걸어 빨리 가고, 나중엔 작게 걸어 바닥에 앉는다. η₀ = 1.05로 발산하던 것도 30걸음 뒤 x = 2.00에 도착한다.

해 볼 것

  1. η = 0.1과 0.9: 10걸음 뒤 같은 곳(2.32). 0.8¹⁰ = (−0.8)¹⁰이기 때문.
  2. η = 1.05 → 점점 줄이기로 바꾸기: 발산이 멈춘다.

기억할 한 줄. η가 작으면 느리고, 크면 지그재그, 더 크면 발산. 처음엔 크게 나중엔 작게가 흔한 해법.

7local minimum과 saddle point

알고 싶은 것

바닥이 여러 개면? 기울기가 0인데 바닥이 아니면?

이 절에 나오는 약자

global minimum
(전역 최솟값). 전체에서 가장 낮은 바닥.
local minimum
(지역 최솟값). 주변보다는 낮지만 가장 낮지는 않은 바닥.
saddle point
(안장점). 한 방향으로는 바닥, 다른 방향으로는 꼭대기. 말안장 모양.

골짜기가 두 개

GD는 "지금 발밑"만 본다. 그래서 어디서 출발하느냐에 따라 도착하는 골짜기가 다르다.

해 볼 것

  1. 곡선 아무 곳이나 누르기: 그곳에서 공이 굴러간다. 아래 띠 = 출발점마다 도착하는 골짜기.
  2. 무작위 시작 20개: 몇 개는 옆 골짜기에 갇힌다.

기울기 0인데 바닥이 아닌 곳

(0, 0)에서 x 방향으로는 바닥, y 방향으로는 꼭대기. y = 0에서 출발하면 y 쪽 기울기가 늘 0이라 여기서 멈춘다.

그림 읽는 법

  • 등고선 지도: 진한 파랑일수록 낮다. 선 = 높이가 같은 곳. 주황 = GD가 걸은 길. 지도를 누르면 그곳에서 출발.

기억할 한 줄. GD는 발밑만 본다. 시작점에 따라 local minimum에 갇히거나 saddle point 근처에서 오래 머문다.

8변수가 둘: gradient vector

알고 싶은 것

parameter가 여러 개면 기울기는 무엇인가? (실제 model은 수백만 개)

이 절에 나오는 약자

∂f/∂x
partial derivative (편미분). 다른 변수는 그대로 두고 x만 조금 바꿨을 때의 기울기.
∇f
nabla f, gradient. 편미분을 모은 vector. 가장 가파른 오르막 방향.
  • ∂f/∂x 가로 방향 기울기
  • ∂f/∂y 세로 방향 기울기
  • ∇f 둘을 합친 화살표 = 오르막
  • −η∇f 반대로 한 걸음

예제: f = x² + 3y², (2, 1)에서 한 걸음 (η = 0.1)

→ 뜻. 1D와 같은 식을 변수마다 한다. ∇f는 등고선에 수직이다 (가장 가파른 방향).

해 볼 것

  1. 지도 아무 곳이나 누르기: 빨간 ∇f는 늘 등고선에 수직, 주황 길은 그 반대로 간다.
  2. 늘림 k = 10: 좁고 긴 골짜기에서 지그재그 (6장의 normalization, 7장의 momentum이 이것을 고친다).
  3. ascent: 같은 화살표를 따라 올라간다 (loss가 커진다).

기억할 한 줄. gradient = 변수마다의 기울기를 모은 화살표. 그 반대로 걸으면 모든 parameter가 한꺼번에 고쳐진다.

9vanishing·exploding gradient 맛보기

알고 싶은 것

층이 10개면 chain rule로 배율을 10번 곱한다. 배율이 1보다 작거나 크면?

  • a 한 층의 배율
  • g₁ 1층이 받는 gradient
  • g_out 출력의 gradient (= 1)

예제

→ 뜻. 0.25는 sigmoid의 가장 큰 기울기. 10층이면 1층의 gradient는 백만분의 1: 거의 배우지 못한다 (vanishing). 1.5면 58배로 튄다 (exploding). 해법은 6장(ReLU, normalization)과 9장(weight 초기화).

기억할 한 줄. 깊은 network의 gradient = 배율의 거듭제곱. 1에서 조금만 벗어나도 사라지거나 터진다.
