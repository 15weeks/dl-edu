CNN - I

convolution과 pooling

그림을 한 줄로 펴지 않고 2D 그대로 본다. 작은 kernel이 그림 위를 미끄러지며 곳곳에서 같은 무늬(획, 경계)를 찾고, pooling이 그림을 줄인다. 8장 FFN보다 parameter는 적고 정확도는 높다.

1convolution의 개념: kernel이 미끄러진다

알고 싶은 것

그림의 어디에 "세로 경계"가 있는지 작은 숫자판 하나로 찾을 수 있나?

이 절에 나오는 약자

CNN
convolutional neural network. convolution 층을 쓰는 신경망.
kernel (filter)
그림 위를 미끄러지는 작은 weight 판 (여기서는 3×3).
feature map
kernel이 지나가며 만든 출력 그림. "이 무늬가 어디에 얼마나 있나"의 지도.
  • x 입력 그림
  • k kernel
  • y 출력 (feature map)

말로: kernel을 그림 위에 겹치고, 겹친 9칸끼리 곱해서 모두 더하면 출력 한 칸. 한 칸 옮겨 다시. 같은 kernel을 그림 전체에 쓴다 (weight 공유).

예제: 출력 (2, 0) 한 칸

입력의 2~4째 줄, 0~2째 열 창과 세로 경계 kernel을 칸끼리 곱해 더한다.

→ 뜻. 왼쪽이 어둡고 오른쪽이 밝으면 큰 양수, 반대면 큰 음수, 고르면 0. 이 kernel은 "세로 경계 탐지기"다. (딥러닝의 convolution은 수학의 cross-correlation: kernel을 뒤집지 않는다.)
kernel

기억할 한 줄. convolution = 작은 kernel을 미끄러뜨리며 칸끼리 곱해 더하기. 같은 kernel이 그림 어디서든 같은 무늬를 찾는다.

2feature map과 kernel

알고 싶은 것

kernel 숫자를 바꾸면 출력이 어떻게 바뀌나? 학습한 CNN의 kernel은 어떻게 생겼나?

미리 정한 kernel

예제: 이 장의 MNIST CNN

→ 뜻. kernel 하나가 feature map 하나를 만든다 (8개 → 8장). 둘째 층의 kernel은 앞 층의 8장을 모두 본다 (5×5×8). 위 그림의 kernel은 사람이 정하지 않고 학습으로 정해졌다. feature map을 보면 어떤 것은 획 전체를, 어떤 것은 한쪽 경계를, 어떤 것은 바탕을 강조한다.

기억할 한 줄. kernel 수 = 출력 channel 수 = feature map 수. weight shape는 (C_out, C_in, k, k).

3stride, padding과 출력 크기 공식

알고 싶은 것

kernel을 두 칸씩 옮기거나 가장자리에 0을 두르면 출력은 몇 칸이 되나?

이 절에 나오는 약자

N, K
입력 한 변의 칸 수, kernel 한 변의 칸 수.
S (stride)
kernel이 한 번에 옮기는 칸 수.
P (padding)
가장자리에 두르는 0의 줄 수.

예제

→ 뜻. padding (K − 1)/2에 stride 1이면 크기가 그대로("same"), stride 2면 반으로. padding이 없으면 층마다 K − 1칸씩 줄어든다.

기억할 한 줄. O = ⌊(N + 2P − K)/S⌋ + 1. 모든 CNN shape 계산은 이 한 줄이다.

4transpose convolution

알고 싶은 것

convolution이 그림을 줄인다면, 거꾸로 키우는 층은? (10장 decoder, 12장 U-Net)

말로: 입력 한 칸이 (그 값 × kernel)을 출력에 도장처럼 찍는다. stride만큼 건너뛰며 찍고, 겹치는 곳은 더한다.

예제: 입력 2×2, kernel 3×3 (모두 1), stride 2

→ 뜻. 가운데 10 = 1 + 2 + 3 + 4: 네 도장이 모두 겹친 곳. kernel도 학습하므로 "어떻게 키울지"를 배운다. (PyTorch F.conv_transpose2d로 확인)
stride
up = nn.ConvTranspose2d(16, 8, kernel_size=3, stride=2)   # (16, 7, 7) → (8, 15, 15)

기억할 한 줄. transpose convolution = 값 × kernel을 찍어 더하기. 그림을 키운다: O = (N − 1)S − 2P + K.

5max·mean pooling, pool이냐 stride냐

알고 싶은 것

feature map을 반으로 줄이는 가장 간단한 방법은?

예제: 4×4 → 2×2 (2×2 칸마다 하나)

→ 뜻. max는 "그 구역에 무늬가 있었나"만 남긴다: 무늬가 1~2칸 옮겨져도 같은 답이 나오기 쉽다. 학습할 parameter는 없다.
줄이는 방법codeparameter특징
max poolnn.MaxPool2d(2)0정해진 규칙. 빠르고 작은 이동에 강하다.
stride 2 convnn.Conv2d(8, 8, 3, stride=2, padding=1)584줄이는 법도 학습한다. 요즘 큰 network(ResNet 등)가 자주 쓴다.

기억할 한 줄. pooling = 2×2마다 하나 (max 또는 mean). 크기는 반, parameter는 0.

7CNN으로 MNIST, Gaussian 분류, feature map 들여다보기

알고 싶은 것

CNN은 FFN보다 무엇이 나은가?

결과: MNIST 28×28, 3 epoch, 시험 10,000장 (PyTorch)

→ 뜻. parameter가 1/4도 안 되는데 더 정확하다. kernel을 그림 전체에 같이 쓰니 weight가 적고, 가까운 칸끼리 본다는 그림의 성질을 그대로 쓰기 때문이다.

결과: 숫자를 옆으로 옮기면 (학습 때는 옮기지 않았다)

→ 뜻. 같은 kernel이 어디서든 같은 무늬를 찾고 pooling이 작은 이동을 흡수하니 CNN이 훨씬 버틴다. 그래도 많이 옮기면 CNN도 떨어진다: 완전히 이동에 무관하지는 않다.

결과: Gaussian 폭 분류 (학습 4,000장, 시험 1,000장)

→ 뜻. 둥근 덩어리가 어디 있든 "폭"을 재야 하는 문제. 위치가 바뀌어도 같은 kernel이 같은 모양을 잰다.

기억할 한 줄. CNN = 적은 weight로 그림의 "가까운 칸, 어디서나 같은 무늬"를 쓴다. 그래서 더 정확하고 이동에 강하다.

8image transform과 custom DataLoader

알고 싶은 것

학습 그림을 매번 조금씩 바꿔서 넣으려면? 내 data를 DataLoader에 넣으려면?

from torchvision import transforms as T
train_tf = T.Compose([
    T.RandomRotation(15),
    T.RandomAffine(0, translate=(0.1, 0.1)),
    T.ToTensor(),                      # PIL → (C, H, W), 0~1
    T.Normalize((0.5,), (0.5,)),       # → −1~1
])
test_tf = T.Compose([T.ToTensor(), T.Normalize((0.5,), (0.5,))])
class MyData(torch.utils.data.Dataset):
    def __init__(self, imgs, labels, tf=None):
        self.imgs, self.labels, self.tf = imgs, labels, tf
    def __len__(self):
        return len(self.imgs)
    def __getitem__(self, i):          # 한 장씩, 그때그때 transform
        x = self.imgs[i]
        if self.tf: x = self.tf(x)
        return x, self.labels[i]
loader = torch.utils.data.DataLoader(
    MyData(imgs, labels, train_tf), batch_size=64, shuffle=True)

기억할 한 줄. 무작위 transform은 학습 data에만, Normalize는 학습·시험 모두에. Dataset은 __len__과 __getitem__ 두 개면 된다.
