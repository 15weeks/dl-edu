sequence, GRU, LSTM

순서가 있는 data(시계열, 글, 소리)를 한 칸씩 읽으며 "지금까지의 요약" hidden state를 넘겨 가는 network. gate로 기억을 조절하는 GRU·LSTM, 그리고 먼 과거를 잊는 한계까지 (14장 attention의 출발점).

2RNN의 작동: hidden state가 이어진다

알고 싶은 것

"지금까지 읽은 것"을 숫자 몇 개로 들고 다니려면?

이 절에 나오는 약자

RNN
recurrent neural network. 출력 일부(h)를 다음 칸의 입력으로 되돌려 넣는 network.
hidden state h_t
t번째 칸까지 읽은 것의 요약.
  • x_t 지금 칸의 입력
  • h_{t−1} 바로 앞의 요약
  • h_t 새 요약

예제: 숫자 하나짜리 RNN, w_x = 0.5, w_h = 0.8, b = 0, 입력 1, 0, 0, 1, h₀ = 0

→ 뜻. 입력이 0인 동안에도 h는 0.46 → 0.35 → 0.28로 첫 1을 조금씩 잊어 가며 들고 간다. 마지막 1이 들어오면 남은 기억 0.28 위에 더해진다.

기억할 한 줄. RNN = 같은 weight로 한 칸씩: h_t = tanh(W_x x_t + W_h h_{t−1}). h가 기억이다.

5hidden state와 embedding

알고 싶은 것

글자나 단어는 숫자가 아닌데 어떻게 넣나? 다음 글자를 맞히는 LSTM은 무엇을 배우나?

  • E 글자마다 학습되는 8개짜리 벡터 표 (nn.Embedding)
  • T 온도: 크면 고르게, 작으면 가장 그럴듯한 것만
학습하며 만든 글 (Lorem ipsum의 출처인 Cicero 원문 1,848글자로 학습, 온도 0.8)
학습 횟수loss"l"로 시작해 만든 글

처음에는 아무 글자나, 100번이면 라틴어 같은 새 단어, 300번이면 단어 모양이 거의 맞고, 1,500번이면 원문을 그대로 외워 낸다 (글이 1,848글자뿐이라 overfitting, 5장). embedding 지도에서는 모음(a, e, i, o, u)이 한쪽에 모였다: 아무도 모음을 알려 주지 않았지만, 다음 글자를 맞힐 때 모음끼리 비슷한 자리에 쓰이기 때문이다.

기억할 한 줄. embedding = 글자·단어를 학습되는 벡터로 바꾸는 표. 다음 글자 예측만으로 철자와 단어를 배운다.

6GRU와 LSTM: gate로 기억 조절

알고 싶은 것

무엇을 잊고 무엇을 남길지 network가 스스로 정하게 하려면?

  • f forget: 옛 기억을 얼마나 남길지
  • i input: 새것을 얼마나 넣을지
  • o output: 기억을 얼마나 내보일지
  • c cell 상태 (긴 기억)
입력 8, hidden 64gate 묶음parameter특징
RNN14,736가장 단순, 오래 기억하기 어렵다
GRU3 (z, r, h̃)14,208c 없이 h 하나, z가 "남길지 바꿀지"
LSTM4 (i, f, g, o)18,944따로 있는 c가 긴 기억 통로

기억할 한 줄. LSTM의 c_t = f·c_{t−1} + i·g: forget이 1에 가까우면 기억과 gradient가 오래 간다. GRU는 더 가벼운 친척.

7RNN의 한계 → attention으로

알고 싶은 것

100칸 앞의 입력이 마지막 출력에 얼마나 영향을 주나? 실제로 먼 것을 기억할 수 있나?

결과 1: hidden 32, 100칸, 학습 전 (PyTorch autograd), 50칸 앞 입력의 gradient

→ 뜻. 칸마다 0.5배 남짓이 곱해져 멀수록 지수적으로 작아진다 (12장 3절과 같은 이유). forget gate를 1 가까이(bias 3 → σ(3) = 0.95)에서 시작하면 c를 통해 gradient가 거의 그대로 온다.

결과 2: 0/1 무작위 sequence의 첫 글자를 T칸 뒤에 맞히기, hidden 16, 2,000번 학습, seed 3개 중 성공

→ 뜻. LSTM이라고 저절로 오래 기억하지는 않는다: 초기값과 학습 시간에 따라 다르다. 80칸이면 이 학습량으로는 셋 다 찍는 수준이다. 게다가 RNN은 한 칸씩 차례로 계산하므로 긴 글은 느리다. 14장의 attention은 모든 칸을 한 번에, 거리에 상관없이 바로 본다.

기억할 한 줄. RNN의 기억은 칸마다 곱해지며 옅어진다. gate가 늦출 뿐 없애지는 못한다 → attention.
