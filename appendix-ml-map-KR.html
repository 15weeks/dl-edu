ML 지도

딥러닝 밖의 machine learning 키워드

Machine learning 전체를 7단계로 나눈 지도에서, DL-Edu 본문(3~15장)이 다루지 않은 키워드를 모았다. 키워드마다 한 줄 뜻, 핵심 식, 작은 숫자 예제를 두고, 단계마다 browser에서 직접 학습하는 그림을 하나 이상 둔다.

1Classic ML: 선, 이웃, 확률로 나누기

알고 싶은 것

신경망 없이도 점을 두 무리로 나눌 수 있다. 방법마다 무엇을 기준으로 경계를 긋나?

이 절에 나오는 약자

supervised learning
지도 학습. 정답 label y가 붙은 data로 x → y를 배운다. DL-Edu 3~9장이 모두 이것이다.
SVM
support vector machine. 두 무리 사이의 여백(margin)이 가장 넓은 경계를 고른다.
k-NN
k-nearest neighbors. 가장 가까운 k개 점의 다수결.
NB
Naive Bayes. 특징끼리 서로 독립이라고 "순진하게" 가정한 Bayes 규칙.
키워드한 줄 뜻핵심 식DL-Edu와의 연결
supervised learning정답이 있는 예제로 x → y를 배운다min Σ L(f(xᵢ), yᵢ)3~9장 전체
logistic regression선형 점수를 sigmoid로 확률로 바꾼다p = σ(w·x + b)3장의 neuron 하나와 같다
SVM여백이 가장 넓은 선. 경계 가까운 점(support vector)만 경계를 정한다max 2/‖w‖, yᵢ(w·xᵢ + b) ≥ 1hinge loss. kernel을 쓰면 곡선 경계
k-NN가장 가까운 k개의 다수결. 학습 단계가 없다ŷ = 다수결(N_k(x))k가 작으면 overfitting (5장)
Naive Bayesclass마다 특징의 확률을 곱해 비교P(y | x) ∝ P(y) Π P(xⱼ | y)spam filter의 고전
  • w 경계에 수직인 방향 (짧을수록 여백이 넓다)
  • y class (spam / 정상)

말로: SVM은 "두 무리에 가장 넓은 도로를 깐다". Naive Bayes는 "이 단어들이 spam에서 나올 확률 × spam의 흔한 정도"를 정상 쪽과 비교한다.

예제: Naive Bayes로 spam 판정

mail의 40%가 spam이다. "free"라는 단어는 spam의 50%, 정상 mail의 5%에 나온다. "free"가 든 mail이 spam일 확률은?

→ 뜻. 단어 하나로 40% → 87%. 단어가 여럿이면 각 단어의 확률을 계속 곱한다(그래서 "독립"을 가정한다).

SVM: 경계 w = (1, 1), b = −3이면 점 (2, 2)에서 w·x + b = 1 → margin 위의 support vector다. 도로 폭은 2/‖w‖ = 2/√2 = 1.414.

해 볼 것

  1. 덩어리: 네 방법의 시험 정확도가 비슷하다. 직선 하나로 충분한 data다.
  2. 반달: logistic regression과 SVM은 직선, Naive Bayes는 타원 경계라 시험 88~89%에서 멈춘다. k-NN만 휘어진 경계를 따라가 100%가 된다.
  3. 덩어리 data에서 k-NN, k = 1: 학습 100%인데 시험 84%, 경계가 들쭉날쭉하다(overfitting). k = 7이면 시험 92%. SVM에서는 검은 고리가 support vector다.
방법
data

기억할 한 줄. logistic regression = 확률, SVM = 가장 넓은 도로, k-NN = 이웃 다수결, Naive Bayes = 확률을 곱해 비교. 경계가 직선인지 휘는지가 가장 큰 차이다.

2Trees & Ensembles: 스무고개와 그 모음

알고 싶은 것

"x₁ < 0.3인가?" 같은 질문을 하나씩 던져 data를 나누면? 그런 tree를 여러 개 모으면 왜 더 좋아지나?

이 절에 나오는 약자

CART
classification and regression tree. 가장 흔한 decision tree 만드는 법.
Gini
Gini impurity. 한 마디(node) 안이 얼마나 섞였나. 한 class뿐이면 0.
bagging
bootstrap aggregating. 중복 허용으로 다시 뽑은 data로 model을 여러 개 만들어 평균.
boosting
약한 model을 순서대로 더하며, 앞 model이 틀린 곳을 다음 model이 고친다.
XGBoost
eXtreme Gradient Boosting. 2차 미분과 정규화를 쓰는 빠른 gradient boosting library.
키워드한 줄 뜻핵심 식특징
decision tree축에 평행한 질문으로 한 번에 한 칸씩 나눈다Gini = 1 − Σ p_k²을 가장 많이 줄이는 질문읽기 쉽다. 깊으면 overfitting
random forest다시 뽑은 data + 무작위 특징으로 tree 여러 개, 평균p = (1/B) Σ p_bbagging. 흔들림(variance)을 줄인다
AdaBoost틀린 점의 weight를 키워 다음 model이 거기에 집중α = ½ ln((1 − ε)/ε)boosting의 시작 (1995)
gradient boosting남은 오차(= −gradient)에 작은 tree를 더해 간다F_m = F_{m−1} + η h_m함수 공간의 gradient descent (2·7장)
XGBoostgradient boosting + 2차 미분 + tree 크기 벌점Obj = Σ L + Σ (γT + ½λ‖w‖²)표 형태 data의 강자
  • p_k 한 마디 안 class k의 비율
  • η 한 번에 더하는 크기 (learning rate)

말로: tree는 섞임(Gini)이 가장 많이 주는 질문을 고른다. boosting은 "지금 model이 틀린 만큼"을 다음 tree가 배워서 조금씩 더한다.

예제 ②: AdaBoost의 weight

→ 뜻. 틀린 20%의 weight는 2배, 맞힌 80%는 절반. 다시 합을 1로 맞추면 틀린 점이 전체 weight의 정확히 50%가 된다. 다음 model은 반드시 그 점들을 신경 써야 한다.

예제 ③: gradient boosting 한 round

→ 뜻. 첫 model은 평균 하나. 둘째 tree(stump)는 "처음 둘은 낮게, 셋째는 높게"를 배우고, η = 0.5만큼만 더한다. 이것을 수백 번 반복한다.

해 볼 것: (가) tree 하나와 forest

  1. decision tree, 깊이 1 → 3 → 10: 경계가 계단처럼 잘게 나뉜다. 처음 data에서 학습 정확도는 87.5% → 100%로 오르는데, 시험 정확도는 깊이 5부터 87.5%에서 멈춘다.
  2. random forest, 깊이 10 (tree 20개): 경계가 부드러워지고 시험 정확도가 90%로 오른다. tree 수 1 → 60으로 바꿔 본다.
model

해 볼 것: (나) gradient boosting

  1. round 0 → 1 → 5: 평균 한 줄에서 계단이 하나씩 생긴다. 빨간 선(남은 오차)이 짧아진다.
  2. η 1.0: 몇 round 만에 맞지만 잡음까지 따라간다. η 0.1: 천천히 내려간다. 그래서 실제로는 작은 η + 많은 round를 쓴다.
η

기억할 한 줄. tree = 섞임을 가장 줄이는 질문의 연속. forest = tree 여러 개의 평균(흔들림 감소). boosting = 남은 오차를 다음 tree가 배워 조금씩 더하기.

3Clustering: 정답 없이 무리 짓기

알고 싶은 것

label이 없는 점들에서, 가까운 것끼리 무리를 짓는 방법은? 무리 수는 누가 정하나?

이 절에 나오는 약자

unsupervised learning
비지도 학습. 정답 label 없이 data의 구조를 찾는다. 10장 autoencoder도 여기에 속한다.
DBSCAN
density-based spatial clustering of applications with noise. 점이 빽빽한 곳을 따라 무리를 넓힌다.
ε, minPts
DBSCAN의 이웃 반지름과, core가 되는 데 필요한 이웃 수.
linkage
두 무리 사이 거리를 재는 방법: single(가장 가까운 두 점), complete(가장 먼 두 점), average(평균).
키워드한 줄 뜻핵심 식특징
k-means"가까운 중심에 배정" ↔ "중심을 평균으로 이동"을 반복J = Σ ‖x − μ_c(x)‖²k를 미리 정한다. 둥근 무리에 맞다
k-means++시작 중심을 서로 멀리 퍼뜨려 뽑는다P(x) ∝ D(x)²나쁜 시작을 줄인다
hierarchical가장 가까운 두 무리를 계속 합쳐 tree(dendrogram)를 만든다single / complete / average linkage자르는 높이로 무리 수를 고른다
DBSCAN반지름 ε 안에 이웃이 minPts 이상인 core에서 무리가 퍼진다|N_ε(x)| ≥ minPts모양이 자유롭고, noise를 따로 표시한다
  • μ_k k번째 무리의 중심
  • c(i) 점 i가 속한 무리
  • J 점과 자기 중심 사이 거리²의 합

말로: (1) 배정과 (2) 이동 모두 J를 줄이거나 그대로 둔다. 그래서 반드시 멈춘다. 다만 멈춘 곳이 가장 좋은 답이라는 보장은 없다(시작에 따라 다르다).

예제: 1차원 k-means (점 1, 2, 3, 9, 10, 11, 시작 중심 1과 4)

→ 뜻. 3이 처음엔 시작 중심 4 쪽에 붙었다가, 중심이 옮겨 가자 제자리(왼쪽 무리)로 돌아왔다. step 3에서는 배정이 바뀌지 않아 끝난다.

해 볼 것: (가) k-means와 DBSCAN

  1. 덩어리 + k-means: "한 step"을 여러 번 누르며 J가 줄어드는 것을 본다. "새 data"로 여러 번 다시 하면 가끔 한 중심이 두 덩어리를 먹는다. k-means++로 바꾸면 이런 일이 드물다.
  2. 반달 + k-means (k = 2): 두 반달을 직선으로 반씩 자른다. DBSCAN (ε 0.35~0.5)은 두 반달을 그대로 찾는다.
  3. DBSCAN에서 ε를 작게(0.2): 무리가 잘게 쪼개지고 noise(회색)가 많다. 0.6 이상: 두 반달이 한 무리로 붙는다.
방법
data

해 볼 것: (나) hierarchical clustering

  1. 자르는 높이(빨간 점선)를 내리면 무리 수가 늘어난다. 맨 위에서 자르면 1개, 맨 아래면 점마다 1개.
  2. single linkage는 가장 가까운 두 점만 보므로 합치는 높이가 낮다. complete는 가장 먼 두 점을 보므로 높다.
linkage

기억할 한 줄. k-means = 중심 k개와 평균 이동의 반복(k-means++는 좋은 시작). hierarchical = 합친 순서의 tree를 원하는 높이에서 자르기. DBSCAN = 빽빽한 곳을 따라 퍼지고, 외톨이는 noise.

4Compress & Detect: 줄여서 보기, 이상한 점 찾기

알고 싶은 것

10차원 data를 눈으로 보려면 2차원으로 줄여야 한다. 무엇을 남기고 줄이나? 그리고 label 없이 "보통과 다른 점"을 찾으려면?

이 절에 나오는 약자

PCA
principal component analysis. 분산이 가장 큰 방향(principal component, PC)으로 투영한다.
t-SNE
t-distributed stochastic neighbor embedding. 가까운 이웃 관계를 지키며 2D로 펼친다.
KL
Kullback–Leibler divergence. 두 확률 분포가 얼마나 다른가 (1장 cross-entropy와 짝).
perplexity
t-SNE에서 "이웃으로 볼 점 수"의 대략적인 크기.
키워드한 줄 뜻핵심 식특징
PCA분산이 가장 큰 방향으로 투영 (선형)Σv = λv, 남는 비율 λ₁ / Σλ빠르고 되돌릴 수 있다. autoencoder(10장)의 선형판
t-SNE이웃 관계를 지키는 2D 그림 (비선형)min KL(P ‖ Q), q ∝ (1 + ‖yᵢ − yⱼ‖²)⁻¹보기용. 무리 사이 거리와 무리 크기는 믿지 말 것
isolation forest무작위로 자르면 이상한 점은 빨리 혼자가 된다s = 2^(−E[h] / c(n))label 없는 이상 탐지

  • y 2D 그림 위의 위치

5Reinforcement Learning: 보상으로 배우기

알고 싶은 것

정답 대신 "잘했다(+) / 못했다(−)"라는 보상만 받으면서, 어떤 상황에서 무엇을 할지 배울 수 있나?

이 절에 나오는 약자

RL
reinforcement learning, 강화학습. agent가 환경에서 행동하고 보상을 받으며 배운다.
MDP
Markov decision process. 상태 s, 행동 a, 보상 r, 다음 상태의 확률로 정한 문제.
Q(s, a)
행동 가치. 상태 s에서 a를 하고 그 뒤로 잘 행동했을 때 받을 보상 합의 기댓값.
SARSA
State, Action, Reward, next State, next Action. 고치는 데 쓰는 다섯 값의 머리글자.
DQN
deep Q-network. Q 표 대신 신경망으로 Q를 계산한다 (Atari, 2015).
ε-greedy
확률 ε로 무작위 행동(탐험), 나머지는 가장 좋은 행동.
키워드한 줄 뜻핵심 식특징
MDP강화학습 문제를 적는 틀(S, A, P, R, γ)γ = 미래 보상의 할인율
Q-learning다음 상태의 최고 값으로 Q를 고친다 (off-policy)Q ← Q + α[r + γ max Q(s′, ·) − Q]탐험과 상관없이 최적 경로를 배운다
SARSA실제로 고른 다음 행동의 값으로 고친다 (on-policy)Q ← Q + α[r + γ Q(s′, a′) − Q]탐험의 위험까지 반영해 조심스럽다
DQNQ를 신경망으로 + replay buffer + target networkL = (r + γ max Q_target − Q_θ)²8·11장의 network를 Q에 쓴 것
policy gradient정책 π(a | s)를 보상이 커지는 쪽으로 직접 미분해 올린다∇J = E[∇ log π(a | s) · G]연속 행동, 확률적 정책

  • α 고치는 크기
  • r 이번 보상
  • γ 미래 보상 할인 (0~1)
  • A advantage: 기대보다 얼마나 좋았나

말로: 대괄호 안 = "방금 겪은 것(r + 다음 상태 가치) − 내가 예상한 것". 예상이 틀린 만큼 α씩 고친다 (TD error). policy gradient는 기대보다 좋았던 행동의 확률을 올린다.

예제 ①: Q 한 번 고치기

→ 뜻. 같은 경험인데 Q-learning은 "다음엔 최고로 하겠지"라고 보고 4.0, SARSA는 "다음에 실제로 고른 행동(탐험일 수도)"을 보고 0.4로 고친다. 이 차이가 아래 절벽 그림의 경로 차이를 만든다.

예제 ②: policy gradient 한 걸음 (팔 3개, 처음엔 모두 1/3)

→ 뜻. 보상을 받은 팔의 확률이 0.333 → 0.356으로 오른다. critic이 있으면 G 대신 advantage를 쓴다: r = 1, V(s) = 4, V(s′) = 5, γ = 0.9이면 A = 1 + 4.5 − 4 = 1.5.

해 볼 것: (가) 절벽 걷기 (cliff walking)

  1. "50 episode 학습"을 6~10번 누른다. Q-learning의 경로(파란 선)는 절벽 바로 위 줄로 가는 가장 짧은 길(13걸음)이다. SARSA로 바꾸면 경로가 한두 줄 위로 돌아간다.
  2. 아래 그래프: 학습하는 동안의 보상은 SARSA(주황)가 대개 더 높다. Q-learning은 절벽 옆을 걷다가 ε 확률의 무작위 행동으로 가끔 떨어진다(−100).
  3. ε를 0.01로 내리고 "처음부터": 탐험이 거의 없으면 SARSA도 짧은 길에 가까워진다.
보기

해 볼 것: (나) policy gradient와 critic

  1. "100번 당기기"를 여러 번: 평균 보상이 가장 큰 팔 3(초록)의 몫이 점점 커진다.
  2. "critic 기준선"으로 바꿔 "처음부터"와 200번 당기기를 여러 번: 평균 속도는 비슷하지만 운 나쁜 경우가 줄어든다. 20번 반복하면 200번 뒤 팔 3 확률의 최솟값이 0.61 → 0.69로 오른다 (평균은 0.85 vs 0.84).
기준선

기억할 한 줄. 강화학습 = 보상으로 배우기. Q-learning은 최고값으로(대담), SARSA는 실제 다음 행동으로(조심) 고친다. policy gradient는 정책을 직접 올리고, critic은 기준선으로 흔들림을 줄인다.

6Genetic Algorithm: 진화로 답 찾기

알고 싶은 것

미분을 할 수 없거나 봉우리가 여러 개인 문제에서, 생물의 진화를 흉내 내어 좋은 답을 찾을 수 있나?

이 절에 나오는 약자

GA
genetic algorithm, 유전 알고리즘. 후보 답 무리를 세대마다 고르고, 섞고, 조금 바꾼다.
fitness
적합도. 답 하나의 점수.
elitism
가장 좋은 몇 개는 그대로 다음 세대로 넘긴다.

population후보 답 여러 개 (그림에서는 점 20개)세대마다 새로 만든다

  • f 점수 (fitness)
  • a, b 두 부모
  • σ mutation 크기

말로: 점수 비율대로 부모를 뽑고(selection), 둘을 섞고(crossover), 살짝 흔든다(mutation). gradient가 필요 없다.

예제: 1의 개수를 늘리는 문제 (OneMax, 8 bit)

→ 뜻. 셋째 bit 뒤에서 잘라 바꿔 붙이면 부모의 좋은 부분이 모인 자식이 생길 수 있다. 점수 6인 답은 점수 3인 답보다 두 배 자주 부모가 된다.

해 볼 것

  1. 처음 무리 20개(보라 점)는 지형 전체에 흩어져 있다. "한 세대"를 몇 번: 점들이 봉우리 쪽으로 모인다.
  2. "30세대" (mutation 0.25): 대부분 가장 높은 봉우리(1.0, 검은 고리) 꼭대기에 닿는다 (20번 중 19번). 가끔 왼쪽 아래 0.7 봉우리에 남는다.
  3. mutation 0으로 "처음부터" → "30세대"를 여러 번: 섞기만 하면 무리가 금방 한 곳으로 줄어들어, 꼭대기에 못 닿거나 낮은 봉우리에 갇힌다 (20번 중 8번). mutation이 탐험과 마무리를 맡는다.

기억할 한 줄. GA = selection(좋은 것을 부모로) + crossover(섞기) + mutation(흔들기)의 반복. 미분이 없어도 되고, mutation이 local optimum에서 빠져나오게 한다.
