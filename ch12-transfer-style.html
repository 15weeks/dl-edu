Transfer learning and style transfer

Borrowing the body of a network that is already trained and using it on a new problem (transfer learning); the residual connection that made very deep CNNs possible; and style transfer, which moves a picture's pattern using feature statistics (the Gram matrix).

1Transfer learning: what, why and when

WHAT WE WANT TO KNOW

What if there are only a few hundred labelled pictures? Can we borrow a network that already learned from other data?

In words: early layers learn things every picture uses, such as edges and textures; late layers learn what fits only that data. So borrow the early layers and attach a new end (head).

for p in body.parameters():
    p.requires_grad = False            # freeze the body (chapter 9, section 8)
model = nn.Sequential(body, nn.Linear(784, 10))   # new head
opt = torch.optim.Adam([p for p in model.parameters() if p.requires_grad], lr=1e-3)

One line to remember. Transfer learning = a body learned on other data + a new head. The less data, the more you freeze.

→ Meaning. Borrowing is 1–2 points better: the edges and strokes a small body learns serve both digits and clothes, but the two datasets differ a lot, so the gain is small. 3Famous CNN architectures: AlexNet, VGG, ResNet

WHAT WE WANT TO KNOW

Which large CNNs can we borrow, and how did they manage to get so deep?

Name (year)conv · fc layersParametersKey idea
AlexNet (2012)5 · 361,100,840GPU, ReLU and dropout; won ImageNet by a wide margin

ResNet-18 (2015)20 · 111,689,512Residual connection h + f(h); trainable up to 152 layers

Counted from the torchvision structures (without weights). The "18" in ResNet-18 is the 17 convs plus 1 fc on the main path; three 1×1 shortcut convs that match sizes bring the conv count to 20.

  • I the term through which the shortcut passes the gradient unchanged (×1)

RESULTS: width 32, 30 tanh layers, factor by which the gradient changes from layer 30 back to layer 0 (mean of 5 random draws; the same calculation as the figure)

→ Meaning. In a plain stack the gradient is multiplied layer after layer and easily vanishes (chapter 9, initialization). With residuals the addition path carries the gradient all the way back to the input side even in deep networks.

One line to remember. AlexNet → VGG (deeper) → ResNet (deeper still, with shortcuts). The residual h + f(h) keeps the gradient alive.

4Transfer with ResNet-18 and VGG-16 (CIFAR10)

WHAT WE WANT TO KNOW

Borrowing a large network trained on ImageNet, how well can we do with only 5,000 photos?

RESULTS AND SETTINGS

CIFAR10, 5,000 training images (500 per class), 2,000 test images. The small CNN trains on the 32×32 images for 30 epochs. ResNet-18 and VGG-16 see the images enlarged to 224×224 and normalised with the ImageNet mean and SD; the body is frozen and only the last Linear trains, for 60 epochs. Fine-tuning trains everything at 112×112 for 4 epochs (lr 10⁻⁴).

→ Meaning. Even with the body frozen and only one final layer trained, it is far better than a small CNN trained from scratch. The features learned from ImageNet's 1.28 million images carry over to CIFAR10 photos.
m = torchvision.models.resnet18(weights="IMAGENET1K_V1")
for p in m.parameters():
    p.requires_grad = False
m.fc = nn.Linear(512, 10)                    # train only the new head (5,130)

v = torchvision.models.vgg16(weights="IMAGENET1K_V1")
for p in v.parameters():
    p.requires_grad = False
v.classifier[6] = nn.Linear(4096, 10)        # replace only the last Linear (40,970)

One line to remember. For a photo problem, first borrow a network trained on ImageNet. Match its input size and normalisation.

5Pretraining with autoencoders

WHAT WE WANT TO KNOW

What if only 500 pictures have labels but 60,000 have none? (chapter 10, autoencoders)

RESULTS: conv autoencoder (60,000 FMNIST images, rebuild MSE 0.0095) → encoder + new head on 500 images

→ Meaning. In this small experiment the gain is only about half a point (similar in size to the spread across the 3 runs). Features that rebuild well are not necessarily the best for classifying. Today the same idea (learn without labels first) runs with far bigger networks and data and gives large gains (self-supervised learning).

One line to remember. Learn first from unlabelled data (pretraining), finish with the few labels. Check the size of the gain by experiment.

6Style transfer and the Gram matrix

WHAT WE WANT TO KNOW

Can a picture's "pattern" (style) be written as numbers, leaving out what is where?

  • G_ij how much features i and j are on together at the same positions

WORKED EXAMPLE: 3 feature maps of 4 cells each

Each row of F is one map unrolled. G = F Fᵀ holds the dot products between rows.

→ Meaning. One cell: G₁₂ = 1·1 + 0·1 + 1·0 + 0·0 = 1 (maps 1 and 2 are on together only at the first position). Summing over every position k throws away "where" and keeps only "what goes with what".

One line to remember. Gram matrix = dot products between features. It drops position and keeps how often features appear together = style.

7The style transfer algorithm

WHAT WE WANT TO KNOW

How do we put one picture's pattern onto another picture's content?

  • c content picture
  • s style picture
  • x the picture being made (its pixels change)
  1. Borrow VGG-16 and freeze it. What is trained is not the network but the pixels of picture x.
  2. Content: make a deep layer's feature maps (relu4_2) match c → what is where.
  3. Style: make the Gram matrices of five layers (relu1_1 to relu5_1) match s → colours and texture.
  4. Start x from c and change it 300 times with Adam.
style

Every picture was drawn by tools/ch12_style.py itself (the house, the stained glass, the waves). 160×160, VGG-16, a few seconds per run on an Apple GPU (MPS).

One line to remember. Style transfer = gradient descent on the pixels of "content difference + Gram difference", both measured by a frozen CNN.
