1Regression with an ANN: predicting a number

WHAT WE WANT TO KNOW

How do we predict a number (a height, a price) instead of a class? Does a small loss mean a good model?

TERMS IN THIS SECTION

regression
Predicting a continuous number.
MSE
mean squared error. The mean of (ŷ − y)²; the loss for regression.
r
correlation. How closely ŷ and y move together, from −1 to 1.
  • no activation on the output (linear), so it can produce any number
  • MSE size of the errors
  • r how well the shape matches

WORKED EXAMPLE: same x, same noise (0.5), only the slope differs: m = 1 and m = 0

→ Meaning. The MSE is the same, yet with m = 0, x barely explains y. Do not look at the loss alone; look at r (or the picture) too.

THINGS TO TRY

  1. Train: the blue line moves onto the dashed line (the true slope).
  2. Set m = 0 and train: the MSE is about the same but r is small.

One line to remember. Regression = output a number with no activation and train with MSE. Even when the loss is small, check with r whether the model explains the data.

3An experiment comparing learning rates

WHAT WE WANT TO KNOW

What happens when only the learning rate changes? Is one run enough to judge?

A 2-16-1 network (ReLU) trained for 1000 epochs on the data from section 2 (d = 4). 28 learning rates × 5 seeds were run in advance in PyTorch. Grey dot = one seed, blue line = the mean.

RESULTS

→ Meaning. Too small and 1000 epochs are not enough to learn. A wide range works well, and very large rates get slightly worse again. Results vary from seed to seed, so run an experiment several times and look at the mean.

One line to remember. Sweep the learning rate over a wide range on a log scale, run several seeds, and choose by the mean.

4Stacking layers needs a nonlinearity

WHAT WE WANT TO KNOW

If we stack layers without activations, does the network get any smarter?

In words: two linear layers equal one matrix (W = W₂W₁). Stack ten and it is still one. Activations between the layers prevent this.

WORKED EXAMPLE

HOW TO READ THE FIGURE

  • A grid and three points go through two layers. Left = input, middle = after layer 1, right = after layer 2.

THINGS TO TRY

  1. None → ReLU → tanh: with no activation the grid stays straight parallel lines all the way. ReLU folds it, tanh bends it.
activation between layers

One line to remember. Without activations even a deep network is one straight line. A nonlinear activation must fold and bend space for stacking layers to mean anything.

5Several classes: three kinds of iris

WHAT WE WANT TO KNOW

With three or more classes, how is the output built?

TERMS IN THIS SECTION

iris
Petal and sepal sizes of 150 irises (3 species × 50). A famous practice dataset, in use since 1936.
softmax
Turns several scores into probabilities that add up to 1 (chapter 1, section 5).
CE
cross-entropy. −ln(probability of the correct class).
  • output neurons = number of classes
  • p one probability per class, sum = 1
  • answer = the largest p (argmax)

THE DATA AT A GLANCE (mean petal length and width, cm)

→ Meaning. Setosa sits far away and is easy; versicolor and virginica overlap a little. A 2-8-3 network gets about 96% right.

THINGS TO TRY

  1. Train: the three coloured regions grow.
  2. Click the figure to move the +: near a boundary two bars come out similar (the network is unsure).

One line to remember. K classes → K outputs + softmax + cross-entropy. The answer is the class with the largest probability.

6Depth and breadth, and counting parameters

WHAT WE WANT TO KNOW

Should we add neurons sideways or stack more layers? How many parameters does that make?

TERMS IN THIS SECTION

breadth, width
The number of neurons in one layer.
depth
The number of hidden layers.

WORKED EXAMPLE: 2-16-16-3

→ Meaning. Parameters grow with the square of the width (16×16). Width 32 gives about 4 times as many at the same depth.
outputs

HOW TO READ THE FIGURE

  • Spiral data trained with networks of depth 1–5 × width 2–32 (Adam, 1500 epochs, mean of 3 seeds, precomputed in PyTorch). Cell = test accuracy, small number = parameter count. Click a cell to load that network into the counter above.

One line to remember. Too narrow (width 2–4) and no depth helps. Once wide enough, depth helps a little. Not "more is better": choose by experiment.

7PyTorch: Sequential or a class

WHAT WE WANT TO KNOW

What are the two ways to write the same model (2-16-16-3) in PyTorch?

import torch.nn as nn
# 1) Sequential: list the layers in order
net = nn.Sequential(
    nn.Linear(2, 16), nn.ReLU(),
    nn.Linear(16, 16), nn.ReLU(),
    nn.Linear(16, 3))
import torch, torch.nn as nn
# 2) a class: write forward yourself
class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(2, 16)
        self.fc2 = nn.Linear(16, 16)
        self.out = nn.Linear(16, 3)
    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        return self.out(x)

Parameter counts of the two models: 371 and 371 (the same). Sequential is shorter; a class lets you add branches, conditions and several inputs.

One line to remember. Straight-line models: Sequential. Branching paths or special calculations: a class.

8Can we understand a trained model?

WHAT WE WANT TO KNOW

Can we tell "why" section 5's iris network answers as it does by looking at its weights?

Even a small network has 51 weights tangled together; large models have millions to billions. So "what does it look at" is studied separately: looking at a layer's feature maps (chapter 11), latent space (chapter 10), attention maps (chapter 14).
