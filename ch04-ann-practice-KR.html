3장의 network를 실제 문제에 쓴다: 숫자 맞히기(회귀), 두 무리 나누기, 세 종류 꽃 나누기. 그리고 층을 몇 개, neuron을 몇 개 쓸지 실험으로 본다.

1ANN으로 회귀: 숫자 맞히기

알고 싶은 것

class가 아니라 숫자(키, 가격)를 예측하려면? loss가 작으면 좋은 model인가?

이 절에 나오는 약자

회귀
regression. 연속된 숫자를 예측하는 문제.
MSE
mean squared error. (ŷ − y)²의 평균. 회귀의 loss.
r
correlation (상관계수). ŷ와 y가 함께 움직이는 정도, −1~1.
  • 출력층에 activation이 없다 (linear): 어떤 숫자든 낼 수 있게
  • MSE 크기의 오차
  • r 모양이 맞는 정도

예제: 같은 x, 같은 잡음(0.5), 기울기만 m = 1과 m = 0

→ 뜻. MSE는 같은데 m = 0이면 x로 y를 거의 설명하지 못한다. loss 하나만 보지 말고 r(또는 그림)도 본다.

해 볼 것

  1. 학습: 파란 직선이 점선(진짜 기울기)으로 간다.
  2. m = 0으로 놓고 학습: MSE는 비슷한데 r이 작다.

기억할 한 줄. 회귀 = 출력에 activation 없이 숫자를 내고 MSE로 학습. loss가 작아도 r로 "설명하는가"를 함께 본다.

2두 무리 분류 (qwerties)

알고 싶은 것

두 무리가 가까워질수록 정확도는 어떻게 되나?

이 절에 나오는 약자

qwerties
Udemy 강의에서 쓰는 연습 data 이름. 중심이 다른 두 점 무리.
정확도
accuracy. 맞힌 수 ÷ 전체.

예제: 겹침이 정하는 최고 정확도 (이 그림의 data: x₁ 방향 중심 1과 1 + d, 퍼짐 = 표준편차 1)

가장 좋은 경계는 두 중심의 한가운데 x₁ = 1 + d/2다. 그래도 점이 잡음 때문에 d/2보다 멀리 반대쪽으로 밀리면 틀린다. 그래서 최고 정확도는 "표준편차 1인 잡음이 d/2보다 작을 확률" Φ(d/2)다 (Φ = 표준 정규분포에서 그 값보다 작을 확률).

d = 2이면 잡음이 표준편차 하나(1)보다 클 확률 15.9%만큼 틀린다.

d = 1과 4도 같은 방법으로 구하고, 그림의 network(2-8-1, Adam 150 epoch)가 실제로 얻은 정확도와 비교한다.

→ 뜻. network가 이 한계에 거의 닿았다. d = 2에서 network를 더 키우거나 오래 학습해 84%를 넘긴다면 새 data에도 통하는 규칙이 아니라 이 200개 점의 잡음을 외운 것이다 (5장 overfitting). d = 4의 0.980이 한계보다 조금 높은 것도 점이 200개뿐이라 생긴 우연이다.

해 볼 것

  1. d를 줄인다: 두 무리가 겹치고 오른쪽 곡선의 주황 점이 내려간다. slider를 움직일 때마다 2-8-1 network를 다시 학습한다.

기억할 한 줄. data가 겹치면 어떤 network도 100%를 못 한다. 정확도의 한계는 data가 정한다.

2절의 data(d = 4)로 2-16-1 network(ReLU)를 1000 epoch 학습. learning rate 28개 × seed 5개를 PyTorch로 미리 돌렸다. 회색 점 = seed 하나, 파란 선 = 평균.

결과

→ 뜻. 너무 작으면 1000 epoch 안에 다 배우지 못한다. 넓은 범위에서 잘 되고, 아주 크면 다시 조금 나빠진다. seed마다 결과가 달라서 실험은 여러 번 돌려 평균을 본다.

4층을 쌓으려면 비선형이 필요하다

알고 싶은 것

activation 없이 층만 여러 개 쌓으면 더 똑똑해지나?

말로: 선형 층 두 개는 행렬 하나(W = W₂W₁)와 같다. 열 개를 쌓아도 하나다. 층 사이의 activation이 이것을 막는다.

예제

그림 읽는 법

  • 격자 한 장과 점 3개를 두 층에 통과시킨다. 왼쪽 = 입력, 가운데 = 1층 뒤, 오른쪽 = 2층 뒤.

해 볼 것

  1. 없음 → ReLU → tanh: activation이 없으면 격자가 끝까지 곧은 평행선이다. ReLU는 접고, tanh는 휜다.
층 사이 activation

기억할 한 줄. activation이 없으면 깊은 network도 직선 하나. 비선형 activation이 공간을 접고 휘어야 층을 쌓는 의미가 생긴다.

5여러 class: iris 꽃 세 종류

알고 싶은 것

class가 셋 이상이면 출력을 어떻게 만드나?

이 절에 나오는 약자

iris
붓꽃 150송이(세 종류 × 50)의 꽃잎·꽃받침 크기. 1936년부터 쓰인 유명한 연습 data.
softmax
점수 여러 개를 합이 1인 확률로 (1장 5절).
CE
cross-entropy. −ln(정답 class의 확률).
  • 출력 neuron 수 = class 수
  • p class마다 확률, 합 = 1
  • 답 = 가장 큰 p (argmax)

data 한눈에 (꽃잎 길이, 너비의 평균, cm)

→ 뜻. setosa는 멀리 떨어져 쉽고, versicolor와 virginica는 조금 겹친다. 2-8-3 network는 약 96%를 맞힌다.

해 볼 것

  1. 학습: 세 색 영역이 자란다.
  2. 그림을 눌러 + 를 옮긴다: 경계 근처에서는 막대 두 개가 비슷해진다 (헷갈린다).

기억할 한 줄. class가 K개면 출력 K개 + softmax + cross-entropy. 답은 가장 큰 확률의 class.

6깊이와 너비, parameter 세기

알고 싶은 것

neuron을 넓게 늘릴까, 층을 깊게 쌓을까? parameter는 몇 개가 되나?

이 절에 나오는 약자

너비
breadth, width. 한 층의 neuron 수.
깊이
depth. 숨은 층의 수.

예제: 2-16-16-3

→ 뜻. parameter는 너비의 제곱으로 는다 (16×16). 너비 32면 같은 깊이에서 약 4배.
출력

그림 읽는 법

  • spiral data를 깊이 1~5 × 너비 2~32 network로 학습(Adam, 1500 epoch, seed 3개 평균, PyTorch로 미리 계산). 칸 = 시험 정확도, 작은 숫자 = parameter 수. 칸을 누르면 위 계산기가 그 network로 바뀐다.

기억할 한 줄. 너무 좁으면(너비 2~4) 깊어도 못 배운다. 충분히 넓으면 깊이가 조금 도움이 된다. "많을수록 좋다"가 아니라 실험으로 고른다.

7PyTorch: Sequential과 class

알고 싶은 것

같은 model(2-16-16-3)을 PyTorch에서 쓰는 두 방법은?

import torch.nn as nn
# 1) Sequential: 층을 차례로 나열
net = nn.Sequential(
    nn.Linear(2, 16), nn.ReLU(),
    nn.Linear(16, 16), nn.ReLU(),
    nn.Linear(16, 3))
import torch, torch.nn as nn
# 2) class: forward를 직접 쓴다
class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(2, 16)
        self.fc2 = nn.Linear(16, 16)
        self.out = nn.Linear(16, 3)
    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        return self.out(x)

두 model의 parameter 수: 371과 371 (같다). Sequential은 짧고, class는 중간에 분기·조건·여러 입력을 넣을 수 있다.

기억할 한 줄. 일직선 model은 Sequential, 길이 갈라지거나 특별한 계산이 있으면 class.
