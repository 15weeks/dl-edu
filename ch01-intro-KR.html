기초

딥러닝을 위한 수학·통계·코드

딥러닝은 생각보다 적은 도구로 만들어진다. 숫자를 늘어놓는 법(vector, matrix), 곱해서 더하는 법(dot product), 점수를 확률로 바꾸는 법(softmax), 틀린 정도를 재는 법(cross-entropy), 결과를 믿어도 되는지 재는 법(평균, 분산, t-test), 그리고 이것을 몇 줄로 쓰는 법(NumPy, PyTorch)이다. 이 장은 그 도구를 하나씩 손으로 계산하고, 그림으로 움직여 보며 익힌다. 전문용어는 영어로 쓰고 처음 나올 때 한글을 괄호로 붙였다.

이 페이지 읽는 법

  1. 알고 싶은 것: 질문으로 시작한다.
  2. 이 절에 나오는 약자: 모르는 말은 여기서 먼저 확인한다. 전체 목록은 맨 아래 약자 사전에 있다.
  3. 예제: 하려는 것 → 계산 → → 뜻 상자에서 그 숫자가 무엇을 말하는지.
  4. 직접 해 보기: 그림에 무엇이 있는지, 각 버튼과 slider가 무엇인지, 무엇을 해 보면 무엇이 보이는지. 그림 아래 회색 상자가 지금 설정의 결과를 숫자로 풀어 준다.
  5. 기억할 한 줄로 절을 닫는다. 왼쪽 메뉴(☰ 버튼으로 접고 편다)에서 절 사이를 오간다.

1세상을 숫자로: scalar, vector, matrix, tensor

알고 싶은 것

사진, 글자, 소리는 숫자가 아니다. computer는 이것을 어떻게 계산하나? 딥러닝 code에서 늘 보는 (32, 3, 224, 224) 같은 숫자는 무슨 뜻인가?

이 절에 나오는 약자

scalar
(스칼라). 숫자 하나. 예: 온도 21.5.
vector
(벡터). 숫자를 한 줄로 늘어놓은 것. 예: [키, 몸무게] = [172, 68].
matrix
(행렬). 숫자를 가로·세로 표로 늘어놓은 것. 흑백 사진이 그렇다.
tensor
(텐서). 숫자를 여러 방향(축)으로 늘어놓은 것의 일반 이름. scalar는 0축, vector는 1축, matrix는 2축 tensor다.
shape
(모양). 축마다 숫자가 몇 개인지 적은 것. 예: (28, 28) = 가로 28, 세로 28.
pixel
picture element (화소). 사진의 점 하나. 흑백이면 밝기 숫자 하나, 컬러면 빨강·초록·파랑(RGB) 숫자 세 개.
channel
(채널). 컬러 사진의 R, G, B처럼 같은 자리에 겹쳐 있는 숫자 판의 수.
one-hot
(원-핫). 종류(class) 중 하나만 1이고 나머지는 0인 vector. 글자나 종류를 숫자로 바꾸는 가장 쉬운 방법.

딥러닝 model은 숫자만 계산한다. 그래서 모든 data를 먼저 숫자 묶음으로 바꾼다. 이 묶음의 "모양"이 shape다.

현실의 data → 숫자 묶음 (PyTorch의 shape 순서)
data숫자로 바꾸면shape숫자 개수
오늘 기온21.5()1
사람 한 명 (키, 몸무게)[172, 68](2,)2
손글씨 숫자 흑백 사진밝기 0~1의 표(28, 28)784
컬러 사진 한 장R, G, B 표 세 장(3, 224, 224)150,528
컬러 사진 32장 묶음(batch)위 tensor 32개(32, 3, 224, 224)4,816,896
종류 "개" (고양이, 개, 새 중)one-hot [0, 1, 0](3,)3

예제: 사진 32장 묶음에는 숫자가 몇 개 있나

하려는 것: shape의 숫자를 모두 곱하면 전체 숫자 개수다.

→ 뜻. 사진 32장을 한 번에 model에 넣으면 숫자 약 480만 개를 동시에 계산한다. 딥러닝이 GPU(그래픽 카드)를 쓰는 이유다. shape를 읽는 습관이 딥러닝 code를 읽는 첫걸음이다.

그림 읽는 법

  • 왼쪽: 8 × 8 pixel 흑백 사진. 칸마다 밝기가 있다(흰색 0, 검정 1).
  • 오른쪽: 같은 사진을 숫자로 적은 matrix. computer가 실제로 보는 것은 이 숫자다.

조작

칸 누르기
그 pixel 밝기가 0 → 0.5 → 1 → 0으로 바뀐다. 끌면서 칠할 수도 있다.
버튼
숫자 7을 그리거나, 지우거나, 흑백을 뒤집는다.

해 볼 것

  1. "7 그리기"를 누르고 오른쪽 숫자에서 7 모양의 1들을 찾아보기. 사람 눈에는 그림, computer에는 숫자 64개다.
  2. "흑백 뒤집기": 모든 숫자가 1 − 값으로 바뀐다. 그림의 뜻은 같아도 숫자는 완전히 달라진다.

기억할 한 줄. 딥러닝의 모든 입력은 tensor(숫자 묶음)이고, shape는 축마다 숫자가 몇 개인지 적은 것이다. shape의 숫자를 곱하면 전체 숫자 개수다.

2transpose와 shape: 행과 열 바꾸기

알고 싶은 것

논문과 code에 늘 나오는 Aᵀ, x.T는 무엇이고 왜 필요한가?

이 절에 나오는 약자

Aᵀ
A transpose (전치 행렬). A의 행(가로줄)과 열(세로줄)을 바꾼 것.
Aij
A의 i번째 행, j번째 열에 있는 숫자.
(m × n)
행 m개, 열 n개인 matrix의 shape. "m by n"이라고 읽는다.

transpose는 matrix를 대각선을 축으로 뒤집는 것이다. 첫 번째 행이 첫 번째 열이 된다. shape (m × n)이 (n × m)으로 바뀐다. 다음 절의 dot product와 matrix 곱에서 "모양을 맞추려고" 자주 쓴다.

→ 뜻. A의 1행 (1, 2, 3)이 Aᵀ의 1열이 되었다. 예: A23 = 6은 Aᵀ32 = 6으로 옮겨 간다. 숫자는 그대로이고 자리만 바뀐다.

그림 읽는 법

  • 위: A와 Aᵀ의 숫자 칸. 칸을 누르거나 mouse를 올리면 짝이 되는 두 칸이 파랗게, 그 칸이 있는 A의 행과 Aᵀ의 열이 초록으로 칠해진다.
  • 아래: A의 칸들이 점선 대각선을 거울 삼아 Aᵀ 자리로 옮겨 가는 그림. 파란 칸 = A의 1행, 초록 칸 = A의 2행.

조작

t
0이면 A, 1이면 Aᵀ. 그 사이는 옮겨 가는 중간.
움직이기
t를 0 ↔ 1로 천천히 움직인다.

해 볼 것

  1. A의 6을 누르기: "A의 2행 3열 = Aᵀ의 3행 2열"이 나온다.
  2. "움직이기": 가로로 누운 파란 1행 (1, 2, 3)이 세로 1열로 선다. 대각선 위의 1과 5는 자리가 그대로다.
칸을 눌러 보세요.

기억할 한 줄. transpose = 행과 열을 바꾼다. shape (m × n) → (n × m). 숫자는 그대로, 자리만 바뀐다.

3dot product: 두 vector가 얼마나 같은 방향인가

알고 싶은 것

딥러닝에서 가장 많이 하는 계산은 무엇일까? "같은 자리끼리 곱해서 모두 더하기" 하나다. 이 계산은 무엇을 재나?

이 절에 나오는 약자

a · b
dot product (내적). 같은 자리 숫자끼리 곱해서 모두 더한 값.
|a|
norm (길이). vector의 길이. √(a₁² + a₂² + …).
θ
theta (각도). 두 vector 사이의 각.
w, b
weight, bias (가중치, 치우침). neuron이 입력 x에 곱하는 숫자들과 더하는 숫자 하나.

예제 ①: a = (2, 1), b = (1, 3)

하려는 것: 같은 자리끼리 곱해 더하고, 길이로 나눠 각도를 구한다.

→ 뜻. dot product는 "두 vector가 얼마나 같은 쪽을 보나"를 잰다. 같은 방향이면 크고, 직각이면 0, 반대면 음수다. 길이로 나눈 cos θ만 보면 길이와 상관없이 방향만 비교한다(얼굴 인식이 쓰는 cosine similarity).

예제 ②: neuron 하나는 dot product 하나다

하려는 것: 입력 x = (1, 2, 3), weight w = (0.5, −1, 2), bias b = 0.5일 때 neuron의 점수 z를 구한다.

→ 뜻. neuron은 "입력이 내가 좋아하는 모양(w)과 얼마나 닮았나"를 dot product로 잰다. 3번째 입력(3)에 큰 weight(2)가 곱해져 점수 대부분을 만들었다. 학습은 이 w와 b를 고치는 일이다(2~3장).

그림 읽는 법

  • 파란 화살표 = a, 주황 화살표 = b. 점선 = b를 a 방향으로 비춘 그림자(projection). 그림자 길이 × |a| = a · b다.

조작

화살표 끝 끌기
a나 b의 끝점을 끌어 방향과 길이를 바꾼다.

해 볼 것

  1. 처음 상태(a = (2, 1), b = (1, 3)): a · b = 5, 각도 45°(예제 ①).
  2. b를 a와 직각이 되게 끌기: a · b가 0이 된다. 그림자도 사라진다.
  3. b를 a의 반대쪽으로: a · b가 음수가 되고, 그림자가 a의 반대 방향에 생긴다.

기억할 한 줄. dot product = 같은 자리끼리 곱해서 더하기 = 두 vector가 얼마나 같은 방향인가. neuron 하나의 계산이 바로 이것(w · x + b)이다.

4matrix 곱: dot product를 한꺼번에

알고 싶은 것

neuron이 수백 개면 dot product도 수백 번이다. 이것을 한 번에 적는 방법이 matrix 곱이다. 어떤 규칙으로 계산하고, shape는 어떻게 맞추나?

이 절에 나오는 약자

AB, A @ B
matrix multiplication (행렬 곱). Python에서는 @로 쓴다.
W
weight matrix (가중치 행렬). 행 하나가 neuron 하나의 weight다.

규칙 하나: 결과의 (i, j) 칸 = A의 i번째 행과 B의 j번째 열의 dot product.

shape 규칙: (m × n) @ (n × p) = (m × p). 안쪽 두 숫자(n)가 같아야 곱할 수 있다. dot product를 하려면 길이가 같아야 하기 때문이다.

예제: 결과의 1행 2열 한 칸

하려는 것: A의 1행 (1, 2, 3)과 B의 2열 (0, 1, 1)의 dot product를 구한다.

→ 뜻. 2 × 2 = 4칸이므로 dot product를 4번 한 것이다. neuron 층(layer)으로 보면, W의 행 하나가 neuron 하나의 weight이고 입력 x와의 matrix 곱 W x 한 번이 그 층의 neuron 전부를 한꺼번에 계산한다. GPU는 이 곱을 아주 빨리 한다.

그림 읽는 법

  • A(2 × 3), B(3 × 2), 결과 C = A @ B(2 × 2). 결과 칸을 누르면 그 칸을 만든 A의 행과 B의 열이 칠해진다.

해 볼 것

  1. 결과의 오른쪽 위 칸(5)을 누르기: 예제의 1 × 0 + 2 × 1 + 3 × 1 = 5가 아래에 나온다.
  2. "차례로 보기": 네 칸을 하나씩 돌며, A의 행 하나와 B의 열 하나가 만나 C의 칸 하나가 되는 것을 보여 준다.
  3. "새 숫자"를 눌러 다른 matrix로 직접 손으로 한 칸 계산해 보고, 눌러서 맞는지 확인하기.
결과 C의 칸을 눌러 보세요.

기억할 한 줄. matrix 곱 = dot product를 표 모양으로 한꺼번에. (m × n) @ (n × p) = (m × p), 안쪽 숫자가 같아야 한다. neuron 한 층 = W x 한 번.

5softmax: 점수를 확률로 바꾸기

알고 싶은 것

model의 마지막 층은 종류(class)마다 점수를 낸다. 예: 고양이 2.0, 개 1.0, 새 0.0. 이 점수를 "고양이일 확률 66%"처럼 바꾸려면?

이 절에 나오는 약자

logit
(로짓). softmax에 넣기 전의 점수 z. 음수일 수도 있다.
e
Euler's number (자연상수). 약 2.718. eᶻ는 z가 1 커질 때마다 2.718배 커진다.
T
temperature (온도). 점수를 T로 나눈 뒤 softmax한다. T가 작으면 1등에 몰리고, 크면 고르게 퍼진다.

두 단계다. ① 모든 점수를 eᶻ로 바꿔 양수로 만든다. ② 합으로 나눠 모두 더해 1이 되게 한다.

예제: z = (2, 1, 0), T = 1

→ 뜻. 점수 차이 1이 확률로는 약 2.7배 차이가 된다. 같은 점수에 T = 0.5를 쓰면 (0.867, 0.117, 0.016)으로 1등에 몰리고, T = 2면 (0.506, 0.307, 0.186)으로 퍼진다. 순서(1등)는 T와 상관없이 같다.

그림 읽는 법

  • 왼쪽: 점수 z(logit), 0 위로 양수, 아래로 음수. 오른쪽: softmax 확률, 합은 항상 1. 가장 높은 확률(argmax, 8절)은 진하게 칠해진다.

조작

z₁, z₂, z₃
세 종류(고양이, 개, 새)의 점수.
T
temperature.

해 볼 것

  1. 세 점수에 모두 5를 더해 보기(예: 7, 6, 5): 확률은 그대로다. softmax는 점수의 "차이"만 본다.
  2. T를 0.2로: 거의 1등만 1이 된다. T를 5로: 거의 1/3씩 고르게 된다.

기억할 한 줄. softmax = eᶻ로 양수로 만들고 합으로 나눈다. 결과는 합이 1인 확률이고, 점수의 차이만 중요하다. temperature가 "얼마나 1등에 몰지"를 정한다.

6log와 exp: 곱을 합으로 바꾸는 도구

알고 싶은 것

딥러닝의 loss 식에는 왜 ln(log)이 꼭 들어갈까?

이 절에 나오는 약자

exp(x), eˣ
exponential (지수 함수). e를 x번 곱한 값.
ln x
natural logarithm (자연로그). "e를 몇 번 곱하면 x가 되나". exp의 반대.
underflow
(언더플로). 숫자가 너무 작아져 computer가 0으로 처리하는 것.
  • ln은 exp를 되돌린다: ln(eˣ) = x. 그래프로는 y = x 직선을 거울로 삼아 서로 뒤집은 모양이다.
  • 곱 → 합: ln(a × b) = ln a + ln b. 확률을 여러 개 곱해야 할 때 log를 쓰면 더하기가 된다.
  • 확률(0~1)의 ln은 0 이하다. 확률이 작을수록 ln이 크게 음수다.

예제 ①: 곱이 합이 된다

예제 ②: 작은 확률을 200번 곱하면

→ 뜻. computer의 숫자(float64)는 약 10⁻³⁰⁸보다 작으면 0이 된다. 확률을 그대로 곱하면 금방 0이 되지만, log를 쓰면 −921 같은 보통 숫자로 남는다. 그래서 딥러닝은 확률 대신 log 확률로 계산한다.

그림 읽는 법

  • 파랑 = y = ln x, 주황 = y = eˣ, 회색 점선 = y = x. 두 점은 거울(y = x)을 사이에 둔 짝이다.

해 볼 것

  1. x를 1로: ln 1 = 0. 확률 1(확실함)의 log는 0이다.
  2. x를 0.05까지 줄이기: ln x가 −3 아래로 빠르게 내려간다. 작은 확률일수록 log가 크게 음수다.

기억할 한 줄. ln은 exp의 반대이고, 곱을 합으로 바꾼다. 확률을 곱하면 0이 되어 버리므로 딥러닝은 log 확률을 더한다.

7entropy와 cross-entropy: 놀람의 평균

알고 싶은 것

model이 "정답이 개일 확률 0.7"이라고 했다. 이 답은 얼마나 틀렸나? 숫자 하나로 재는 방법이 cross-entropy이고, 분류 model은 거의 모두 이것을 loss로 쓴다.

이 절에 나오는 약자

surprise
(놀람). 확률 p인 일이 일어났을 때 −ln p. 드문 일일수록 크다.
H(p)
entropy (엔트로피). 놀람의 평균. 결과가 얼마나 예측하기 어려운가.
CE
cross-entropy (교차 엔트로피). 정답 분포 y와 예측 분포 ŷ 사이의 놀람. 정답이 one-hot이면 −ln(정답에 준 확률).
nat, bit
정보량의 단위. ln으로 재면 nat, log₂로 재면 bit. 1 bit = 0.693 nat.

예제 ①: 동전의 entropy

→ 뜻. 반반 동전은 결과를 가장 예측하기 어렵다(entropy 최대). 앞면이 99% 나오는 동전은 거의 놀랄 일이 없다(0.056).

예제 ②: 정답이 "개"일 때 두 model의 cross-entropy

하려는 것: 정답 y = (0, 1, 0)(고양이, 개, 새). one-hot이라 정답 칸의 −ln만 남는다.

→ 뜻. model A는 정답에 0.7을 줘서 loss가 작고, model B는 정답에 0.3만 줘서 loss가 3배 이상 크다. 정답에 확률 1을 주면 loss는 0이다. 학습은 이 숫자를 줄이는 방향으로 weight를 고친다. PyTorch의 nn.CrossEntropyLoss가 이 계산(softmax + −ln)을 한다.

그림 읽는 법

  • 왼쪽: 동전에서 앞면 확률 p에 따른 entropy H(p). 가운데(0.5)가 가장 높다.
  • 오른쪽: model이 정답에 준 확률 q에 따른 cross-entropy −ln q. q가 0에 가까우면 loss가 폭발한다.

해 볼 것

  1. q를 0.7로(예제 model A): 0.357. q를 0.3으로(model B): 1.204.
  2. q를 0.01로: loss 4.6. 확신을 갖고 틀리면 아주 크게 벌을 받는다.

기억할 한 줄. entropy = 놀람(−ln p)의 평균. cross-entropy = model이 정답에 준 확률의 −ln. 분류 model은 이것을 loss로 줄인다.

8min/max와 argmin/argmax: 값과 자리

알고 싶은 것

model이 확률 (0.2, 0.7, 0.1)을 냈다. 최종 답 "개"는 어떻게 고르나?

이 절에 나오는 약자

max, min
가장 큰 값, 가장 작은 값.
argmax, argmin
argument of the maximum / minimum. 가장 큰(작은) 값이 있는 자리(index).
index
(번호). Python은 0부터 센다.

예제: 점수 v = (2.0, 3.5, 1.2) (고양이, 개, 새)

→ 뜻. max는 "얼마나"를, argmax는 "어디"를 알려 준다. 분류에서 답은 argmax다. index 1(0부터 세므로 두 번째) = "개". softmax는 순서를 바꾸지 않으므로 점수의 argmax와 확률의 argmax는 같다. 그래서 답만 필요하면 softmax 없이 점수에서 바로 argmax를 해도 된다. 2장의 gradient descent는 loss의 argmin(loss를 가장 작게 하는 weight)을 찾는 일이다.

기억할 한 줄. max = 가장 큰 값, argmax = 그 값의 자리. 분류의 답은 argmax, 학습의 목표는 loss의 argmin이다.

9mean, variance, standard deviation: 가운데와 퍼짐

알고 싶은 것

model을 5번 학습했더니 정확도가 매번 조금씩 다르다. "보통 얼마"이고 "얼마나 흔들리나"를 숫자 두 개로 말하려면?

이 절에 나오는 약자

x̄, μ
mean (평균). x̄ = 가진 data의 평균, μ = 전체(population)의 참 평균.
variance, σ²
(분산). 평균에서 떨어진 거리의 제곱의 평균.
SD, σ
standard deviation (표준편차). 분산의 제곱근. data와 같은 단위의 "보통 퍼짐".
n − 1
표본에서 분산을 구할 때 n 대신 n − 1로 나누는 보정(sample variance).

예제: x = (2, 4, 4, 4, 5, 5, 7, 9)

한 칸 예: 첫 값 2는 평균 5에서 −3 떨어져 있고, 제곱하면 9다. 제곱을 쓰는 이유는 위아래 거리가 서로 지워지지 않게 하려는 것이다.

→ 뜻. 이 data는 "보통 5이고, 보통 ±2 정도 퍼져 있다". 가진 data가 전체의 일부(표본)이면 n − 1로 나눠 32 ÷ 7 = 4.571, SD 2.138로 조금 크게 잡는다. NumPy의 np.var는 기본이 n으로, PyTorch의 torch.var는 기본이 n − 1로 나눈다.

그림 읽는 법

  • 위: 예제의 data 8개(x₁~x₈). 같은 값 4가 세 번 있어서 겹치지 않게 점마다 한 줄씩 쓴다. 초록 세로선 = 평균, 점에서 평균까지의 가로선 = 거리.
  • 아래: 점마다 거리의 제곱 (x − 평균)²을 막대로 그렸다. 초록 점선 = 막대 높이의 평균 = 분산.

조작

점 끌기
위 그림의 점을 좌우로 끌어 값을 바꾼다(0.5 단위).
처음 값으로
예제 data로 되돌린다.

해 볼 것

  1. x₈(9)을 10으로 끌기: 그 점의 막대가 16에서 약 24로 자라 분산이 4에서 5.11로 커진다. 제곱 때문에 멀리 떨어진 값 하나가 분산을 크게 흔든다.
  2. 모든 점을 한곳에 모으기: 막대가 모두 사라지고 분산이 0이 된다.

기억할 한 줄. 평균 = 가운데, 분산 = 평균에서 떨어진 거리 제곱의 평균, SD = 그 제곱근(같은 단위의 보통 퍼짐).

10random sampling과 seed: 우연을 다시 만들기

알고 싶은 것

딥러닝은 무작위를 많이 쓴다(처음 weight, data 섞기, dropout). 그러면 결과가 매번 다르다. 얼마나 다르고, 같은 결과를 다시 얻으려면 어떻게 하나?

이 절에 나오는 약자

population, sample
(모집단, 표본). 전체와, 그중 뽑은 일부.
sampling variability
(표본 변동). 표본을 다시 뽑을 때마다 평균 같은 숫자가 달라지는 것.
SE
standard error (표준오차). 표본 평균이 흔들리는 정도 = σ ÷ √n.
seed
(씨앗). 무작위 숫자 생성기의 시작값. seed가 같으면 "무작위" 숫자도 똑같이 나온다.
→ 뜻. 시험 점수가 평균 70, SD 10인 집단에서 10명을 뽑아 평균을 내면 보통 ±3.2 정도 흔들린다. 100명이면 ±1로 줄어든다. 100배 많이 뽑아야 흔들림이 1/10이 된다(√100 = 10).
import numpy as np, torch
np.random.seed(42); print(np.random.rand(3))   # [0.3745 0.9507 0.732 ]
np.random.seed(42); print(np.random.rand(3))   # 다시 똑같이 [0.3745 0.9507 0.732 ]
torch.manual_seed(42)                          # PyTorch도 seed를 따로 정한다

그림 읽는 법

  • 왼쪽 회색 = population: 시험 점수(평균 70, SD 10)가 어떻게 퍼져 있나.
  • 오른쪽 파랑 = n명을 뽑아 낸 평균들을 모은 histogram. 빨간 곡선 = 이론이 예측하는 모양(가운데 70, 폭 SE).

조작

n
표본 하나에 뽑는 사람 수.
뽑기 버튼
표본을 1번 또는 1,000번 뽑아 평균을 쌓는다.
seed
이 숫자로 표본 1개를 뽑는다. 같은 seed는 항상 같은 표본을 준다.

해 볼 것

  1. n = 10으로 1,000번: 평균들이 70 ± 3 정도에 모인다. n = 100이면 폭이 1/3로 좁아진다.
  2. seed 42로 두 번 뽑기: 숫자가 똑같다. seed를 43으로 바꾸면 달라진다. 이 page의 생성기는 NumPy와 달라서, 같은 seed라도 NumPy와 같은 숫자는 아니다.
n

기억할 한 줄. 무작위 결과는 뽑을 때마다 흔들리고, 평균의 흔들림은 σ ÷ √n이다. 같은 결과를 다시 얻으려면 seed를 정한다.

11t-test: 두 결과의 차이는 진짜인가

알고 싶은 것

model A는 정확도 평균 0.82, model B는 0.85였다(각 5번 학습). B가 정말 더 좋은가, 아니면 우연인가?

이 절에 나오는 약자

t
t statistic (t 값). 평균 차이 ÷ 그 차이의 흔들림(SE). "신호 ÷ 잡음".
df
degrees of freedom (자유도). data 수에서 정해지는 숫자. t 분포의 모양을 정한다.
p-value
(유의확률). 진짜 차이가 0인데도 이만큼 큰 t가 우연히 나올 확률. 보통 0.05보다 작으면 "우연이라 보기 어렵다"고 한다.
Welch
Bernard L. Welch의 이름. 두 그룹의 퍼짐이 달라도 쓸 수 있는 t-test.

예제: A = (0.81, 0.83, 0.80, 0.82, 0.84), B = (0.84, 0.86, 0.83, 0.85, 0.87)

① 평균: A 0.82, B 0.85, 차이 0.03. ② 각 그룹의 SD(n − 1로 나눔)는 둘 다 0.0158이다.

→ 뜻. 차이(0.03)가 그 흔들림(0.01)의 3배라 우연이라 보기 어렵다(p = 0.017 < 0.05). 같은 0.03 차이라도 흔들림이 0.03이면 t = 1로 우연일 수 있다. 그래서 model을 비교할 때는 여러 seed로 여러 번 돌려서 평균과 흔들림을 함께 본다.

그림 읽는 법

  • 주황 점 = model A의 실행마다 정확도, 파란 점 = model B. 굵은 세로선 = 평균, 가로 막대 = 평균 ± SE.

조작

참 차이
B가 실제로 얼마나 좋은지(시뮬레이션이라 정할 수 있다).
잡음 SD
실행마다 흔들리는 정도.
n
model마다 실행 횟수(seed 수).
다시 뽑기
같은 설정으로 실험을 새로 한 번 한다. 처음 화면은 위 예제의 숫자다.
200번 반복
지금 설정으로 새 실험을 200번 해서 p < 0.05가 몇 번 나오는지 센다.

해 볼 것

  1. 참 차이 0.03, 잡음 0.016, n = 5에서 몇 번 다시 뽑기: t가 대개 2~4 근처이고 p는 자주 0.05 아래다. 200번 반복하면 약 70%가 p < 0.05다.
  2. 잡음을 0.04로: 같은 차이인데 p가 자주 0.05 위로 올라간다(200번 반복에서 약 16%만 p < 0.05). 흔들림이 크면 차이를 믿기 어렵다.
  3. 잡음 0.016으로 돌리고 n을 10으로: 약 98%가 p < 0.05. 실행 횟수를 늘리면 진짜 차이를 더 잘 알아챈다.
  4. 참 차이를 0으로 하고 200번 반복: 그래도 약 5%(20번에 1번)는 p < 0.05가 나온다. 차이가 없는데 나오는 "우연한 유의"다.

기억할 한 줄. t = 평균 차이 ÷ 그 차이의 흔들림. 신호가 잡음보다 충분히 크면(p < 0.05) 우연이라 보기 어렵다. model 비교는 여러 seed로 한다.

경우

13미분 맛보기: 기울기는 "조금 바꾸면 얼마나 변하나"

알고 싶은 것

학습은 loss를 줄이는 쪽으로 weight를 조금씩 고치는 일이다. "어느 쪽으로, 얼마나"는 어떻게 아나? 미분(기울기)이 그 답이다. 자세한 것은 2장에서 하고, 여기서는 감만 잡는다.

이 절에 나오는 약자

dy/dx, f′(x)
derivative (미분, 도함수). x를 아주 조금 바꿨을 때 y가 변하는 비율 = 그 점의 기울기.
h
x를 바꾸는 작은 양.
gradient
(기울기). 변수가 여러 개일 때 미분을 모은 vector.

예제: f(x) = x²에서 x = 3의 기울기

→ 뜻. x = 3에서 x를 조금 늘리면 y는 그 6배만큼 는다. 기울기가 양수이므로 y를 줄이려면 x를 줄여야 한다. 이것이 gradient descent(2장)의 전부다: "기울기의 반대쪽으로 조금 간다". 12절의 PyTorch code가 x.grad = 6을 자동으로 구한 것도 이 값이다.

그림 읽는 법

  • 곡선 = y = x². 초록 직선 = x에서의 접선(기울기 2x). 주황 직선 = x와 x + h를 잇는 할선. h가 작아지면 주황이 초록에 붙는다.

해 볼 것

  1. x = 3, h = 2: 할선 기울기 8 (참값 6과 차이 큼). h를 0.01로 줄이면 6.01이 된다.
  2. x를 0으로: 기울기 0. 곡선의 바닥 = loss의 최솟값(argmin)이 기울기 0인 곳이다.

기억할 한 줄. 미분 = 조금 바꿨을 때의 변화율 = 기울기. 기울기의 반대 방향으로 가면 값이 줄어든다. 학습은 이것을 weight 수백만 개에 동시에 한다.
