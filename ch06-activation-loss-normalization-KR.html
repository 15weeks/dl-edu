Activation·Loss

activation function, loss function, normalization

network를 만들 때 고르는 세 가지: 층 사이의 비선형(activation), 틀린 정도를 재는 법(loss), 숫자 크기를 맞추는 법(normalization). 각각 무엇을 고르면 학습이 잘 되는지 그림으로 비교한다.

1activation function: sigmoid, tanh, ReLU 계열

알고 싶은 것

4장에서 비선형이 꼭 필요하다고 했다. 어떤 모양들이 있고 무엇이 다른가?

이 절에 나오는 약자

ReLU
rectified linear unit. max(0, z).
ELU
exponential linear unit. z < 0에서 eᶻ − 1.
GELU
Gaussian error linear unit. 매끄러운 ReLU.
  • 파란 선 = f(z)
  • 초록 선 = 기울기 f′(z): backprop 때 곱해지는 수 (3장 6절)

예제: z = −2, 0, 2에서 기울기

→ 뜻. sigmoid의 기울기는 아무리 커도 0.25. ReLU는 켜져 있으면 늘 1이라 gradient를 줄이지 않는다.

기억할 한 줄. 숨은 층에는 보통 ReLU 계열(요즘 Transformer는 GELU). sigmoid는 출력층의 확률(0~1)에 쓴다.

2activation의 기울기와 사라지는 gradient

알고 싶은 것

2장 9절의 "층마다 곱해지는 gradient"를 진짜 network에서 재면?

말로: 1층의 gradient에는 위 층들의 f′가 모두 곱해진다. f′ ≤ 0.25인 sigmoid를 10번 곱하면 사라진다.

결과 (숨은 층 10개 × 32, 지금 browser에서 계산)

→ 뜻. sigmoid 숨은 층 10개면 1층은 10층보다 백만 배 느리게 배운다. tanh와 ReLU(알맞은 초기화와 함께, 9장)는 비슷하게 유지한다.
숨은 층

기억할 한 줄. 깊은 network의 숨은 층에 sigmoid를 쓰면 입력 쪽 층이 배우지 못한다. ReLU 계열이 기본이 된 이유.

3loss function: MSE, BCE, cross-entropy

알고 싶은 것

분류에 MSE를 쓰면 안 되나? 두 loss가 같은 예측을 얼마나 다르게 벌하나?

  • p = σ(z), 정답 1에 준 확률
  • p(1 − p) sigmoid의 기울기: 크게 틀리면(p ≈ 0) 0에 가깝다
  • BCE는 이 항이 약분되어 사라진다

예제: 정답 1인데 p = 0.01 (자신 있게 틀림)

→ 뜻. 가장 크게 틀렸을 때 MSE는 거의 고치지 않는다(힘 0.02). cross-entropy는 50배 세게 고친다. 그래서 분류에는 cross-entropy.

기억할 한 줄. 회귀는 MSE, 분류는 cross-entropy. sigmoid/softmax 출력에 MSE를 쓰면 크게 틀린 sample에서 gradient가 사라진다.

print(torch.nn.CrossEntropyLoss()(z, t))                  # softmax를 안에서 한다

print(torch.nn.BCEWithLogitsLoss()(zb, yb))               # sigmoid를 안에서 한다

"…WithLogits"와 CrossEntropyLoss는 sigmoid·softmax를 loss 안에서 더 안정적으로 계산한다. 그래서 model의 마지막 층에는 activation을 넣지 않는다 (점수 z = logit 그대로).

기억할 한 줄. 회귀 → 출력 그대로 + MSE, 분류 → logit 그대로 + CrossEntropyLoss / BCEWithLogitsLoss.

5data normalization: z-score, min-max

알고 싶은 것

입력 숫자의 크기가 서로 다르면(키 170 cm, 시력 1.2) 왜 학습이 느려지나?

  • μ 평균
  • σ 표준편차
  • z-score 뒤: 평균 0, 표준편차 1. min-max 뒤: 0~1
  • μ, σ는 학습 data로만 계산하고 시험 data에도 같은 값을 쓴다

예제: x₂가 x₁보다 5배 큰 두 특성으로 직선 회귀

→ 뜻. (w*까지 1% 안으로 가는 걸음 수, η = 가능한 최대의 50%) 크기가 다르면 loss 골짜기가 길쭉해진다. 가파른 방향에 맞춰 η를 작게 해야 해서, 완만한 방향으로는 기어간다 (2장 8절의 지그재그).

기억할 한 줄. 입력 특성의 크기를 맞추면(z-score) loss 골짜기가 둥글어져 GD가 곧게 빨리 간다.

6batch normalization

알고 싶은 것

입력만이 아니라 숨은 층의 값도 크기를 맞출 수 있나?

이 절에 나오는 약자

BN
batch normalization. 층 안에서 batch마다 평균 0, 분산 1로 맞추는 층.
γ, β
gamma, beta. 맞춘 뒤 다시 늘이고(γ) 옮기는(β) 학습되는 parameter.
ε
epsilon. 0으로 나누지 않으려고 더하는 아주 작은 수.
  • μ_B, σ²_B 이번 batch의 평균과 분산
  • γ, β network가 배우는 수: 필요하면 원래 크기로 되돌릴 수도 있다

예제: batch = [2, 4, 6, 8]

→ 뜻. 학습 때는 batch마다 그 batch의 통계, 평가 때는 학습 내내 모아 둔 running 평균·분산을 쓴다 (5장 6절의 train/eval).

기억할 한 줄. batch norm = 층 안에서 batch마다 평균 0·분산 1로 맞춘 뒤 γ, β로 조절. 학습이 빨라지고 learning rate를 크게 쓸 수 있다.

7예제 data: wine quality

알고 싶은 것

진짜 data에서 정규화는 얼마나 차이를 내나?

빨간 포도주 1599병의 화학 측정값 11개(산도, 당, 알코올 …)와 맛 점수. 점수 > 5면 "좋음"(1)으로 2 class 분류. 출처: Cortez et al., Decision Support Systems, 2009 (UCI Machine Learning Repository, CC BY 4.0).

결과 (PyTorch, 11-16-1, SGD η 0.01, 60 epoch, seed 5개)

→ 뜻. 같은 network, 같은 학습인데 정규화 하나로 13%p. total sulfur dioxide(표준편차 33)와 density(0.002)는 크기가 만 배 넘게 다르다.

기억할 한 줄. 표 형태의 data는 학습 전에 특성마다 z-score부터. 가장 싸고 효과가 큰 처리다.
