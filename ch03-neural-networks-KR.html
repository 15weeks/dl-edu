2neuron 하나 (perceptron)

알고 싶은 것

neuron 하나는 정확히 무슨 계산을 하나?

이 절에 나오는 약자

w, b
weight (가중치), bias (편향). 입력에 곱하는 수와 더하는 수.
z
activation에 넣기 전의 합.
σ
sigma, sigmoid. z를 0~1로 누르는 함수 σ(z) = 1 / (1 + e⁻ᶻ).
perceptron
(퍼셉트론). neuron 하나짜리 분류기. 원래는 step 함수를 쓴다.
  • w 입력마다의 중요도
  • b 기준을 옮기는 수
  • z 합
  • σ activation
  • ŷ 출력

예제: x = (1, 2), w = (0.5, −0.25), b = 0.5

→ 뜻. step이면 z > 0이라 1 ("예"). sigmoid면 "예일 확률 62%".

해 볼 것

  1. w₂를 크게: x₂가 결과를 좌우한다. 선 굵기 = |w|, 파랑 = 양수, 빨강 = 음수.
  2. step ↔ sigmoid: step은 0 아니면 1, sigmoid는 그 사이를 부드럽게 잇는다 (미분이 된다).

기억할 한 줄. neuron = 곱해서 더하고(z = w·x + b) activation을 지난다(ŷ = σ(z)).

3기하로 보면: 경계선 긋기

알고 싶은 것

neuron 하나가 점들을 두 무리로 나눌 때, 그림으로는 무엇을 하나?

  • w 선에 수직인 화살표
  • b 선을 평행하게 민다
  • 오른쪽 식 = perceptron 학습 규칙: 틀린 점 쪽으로 선을 돌린다

해 볼 것

  1. 보라 점(w 끝)을 끌기: 선이 w에 수직으로 따라 돈다.
  2. perceptron 학습: 틀린 점(빨간 고리)을 하나씩 골라(검은 고리) 선을 고친다. 몇 번 만에 끝난다.
  3. data를 XOR로: 아무리 고쳐도 끝나지 않는다. 직선 하나로는 못 나눈다.
data

기억할 한 줄. neuron 하나 = 직선(평면) 하나. 직선으로 못 나누는 data에는 neuron을 층으로 쌓아야 한다.

4forward propagation: 앞으로 계산하기

알고 싶은 것

neuron을 2-2-1로 이으면 예측 ŷ는 어떤 순서로 나오나? 각 단계의 shape는?

이 절에 나오는 약자

2-2-1
입력 2개 → 숨은 neuron 2개 → 출력 1개.
h
hidden (숨은 층) 출력. 입력도 출력도 아닌 가운데 층.
W₁, b₁
1층의 weight 행렬과 bias. W의 행 하나 = neuron 하나.

말로: 층마다 "곱해서 더하고 σ"를 한 번씩. 행렬 곱 한 번이 neuron 여러 개의 계산을 한꺼번에 한다.

예제의 숫자 (그림과 같다)

→ 뜻. 결과 ŷ = 0.595: 정답 1에 59%만 확신한다. 아래 버튼으로 한 단계씩 본다.

기억할 한 줄. forward = 층마다 z = Wa + b, a = σ(z). shape는 (출력 수 × 입력 수) · (입력 수 × 1).

5error, loss, cost

알고 싶은 것

"틀린 정도"를 부르는 세 이름은 어떻게 다른가?

이 절에 나오는 약자

BCE
binary cross-entropy (이진 교차 엔트로피). 0/1 분류의 loss. 1장 7절의 cross-entropy와 같다.
J
cost. 모든 sample의 loss 평균.

말로: 정답이 1이면 −ln ŷ, 0이면 −ln(1 − ŷ). 정답에 준 확률이 작을수록 벌이 급하게 커진다.

예제: 4절의 ŷ = 0.5947, y = 1

→ 뜻. 학습은 cost J를 줄인다. gradient descent(2장)는 J의 기울기를 따라 내려간다.
정답 y

기억할 한 줄. error = 차이(부호 있음), loss = sample 하나의 벌, cost = 전체 평균. 학습은 cost를 줄인다.

6backpropagation: 거꾸로 gradient 구하기

알고 싶은 것

weight 6개 각각을 어느 쪽으로 얼마나 고쳐야 loss가 줄까? chain rule(2장 4절)을 출력에서 입력 쪽으로 층마다 쓴다.

이 절에 나오는 약자

δ
delta. ∂L/∂z: 그 neuron의 합 z를 조금 바꾸면 loss가 얼마나 바뀌나.
⊙
같은 자리끼리 곱하기 (element-wise).
σ′
sigmoid의 기울기 = σ(1 − σ) = h(1 − h).
  • δ 거꾸로 흐르는 신호
  • W₂ᵀδ₂ 같은 weight를 거꾸로 지난다
  • σ′ activation의 기울기를 곱한다 (chain rule)
  • δ · 입력ᵀ = 그 weight의 gradient

예제의 결과

→ 뜻. gradient가 음수인 weight는 키우고, 양수인 weight는 줄이면 loss가 준다. 입력에 가까운 층의 gradient가 더 작다 (σ′ ≤ 0.25를 한 번 더 곱했다: 2장 9절).

기억할 한 줄. backprop = 출력의 δ를 weight를 거꾸로 지나 보내며 σ′를 곱한다. weight의 gradient = δ × 그 weight에 들어온 입력.

예제: η = 0.5로 한 걸음

→ 뜻. 한 번 고쳤더니 정답 쪽 확률이 59% → 68%. 이것을 data 전체에 수천 번 하면 경계가 자란다 (아래 그림).

해 볼 것

  1. 학습: XOR을 직선 몇 개(점선 = 숨은 neuron 하나하나의 경계)를 합쳐 나눈다.
  2. data = 원, 숨은 neuron 2개: 다 못 나눈다 (88%). 3개 이상이면 된다.
  3. η = 0.1: 아주 느리다. η = 3: 빠르지만 흔들린다.
data
점선

기억할 한 줄. 학습 = forward → loss → backprop → 고치기를 data 전체에 수천 번. 숨은 neuron 하나하나는 직선이고, 출력이 그것들을 섞어 굽은 경계를 만든다.

8PyTorch로 같은 계산

알고 싶은 것

4~7절의 손 계산을 PyTorch는 몇 줄로 하나?

이 절에 나오는 약자

nn.Linear(2, 2)
z = Wx + b 층 하나 (W는 2×2).
autograd
automatic differentiation. loss.backward() 한 줄이 6절의 backprop을 전부 한다.
SGD
stochastic gradient descent. W ← W − η·gradient를 해 주는 optimizer.
import torch
net = torch.nn.Sequential(
    torch.nn.Linear(2, 2), torch.nn.Sigmoid(),   # W₁, b₁ → h
    torch.nn.Linear(2, 1), torch.nn.Sigmoid())   # W₂, b₂ → ŷ
with torch.no_grad():                            # 4절의 숫자를 넣는다
    net[0].weight[:] = torch.tensor([[0.4, -0.6], [0.7, 0.2]])
    net[0].bias[:]   = torch.tensor([0.1, -0.3])
    net[2].weight[:] = torch.tensor([[0.9, -0.5]])
    net[2].bias[:]   = torch.tensor([0.2])
x, y = torch.tensor([[1.0, 0.5]]), torch.tensor([[1.0]])
yhat = net(x)                                    # forward (4절)
loss = torch.nn.BCELoss()(yhat, y)               # loss (5절)
loss.backward()                                  # backprop (6절)
print(round(yhat.item(), 4), round(loss.item(), 4))
print(net[2].weight.grad)
print(net[0].weight.grad)
opt = torch.optim.SGD(net.parameters(), lr=0.5)
opt.step()                                       # 고치기 (7절)
print(round(net(x).item(), 4))

출력이 손 계산과 같다: ŷ = 0.5947, L = 0.520, 6절의 gradient, 한 걸음 뒤 ŷ = 0.681.

기억할 한 줄. PyTorch: net(x) = forward, loss.backward() = backprop, opt.step() = 고치기.
