1attention의 아이디어: 어디를 볼까

알고 싶은 것

"it"이 무엇을 가리키는지 알려면 문장의 어느 단어를 봐야 하나? 13장처럼 한 칸씩 넘기지 않고 바로 볼 수 있나?

결과: GPT-2 small (12층 × head 12개)에서 "it"이 "animal"을 가장 많이 보는 head

→ 뜻. 단어마다 앞의 모든 단어에 "얼마나 볼지" 비율(합 1)을 정하고, 그 비율로 정보를 섞어 온다. 거리가 멀어도 한 번에 본다. 다른 head는 전혀 다른 것을 본다 (층·head slider).

기억할 한 줄. attention = 단어마다 "다른 단어를 얼마나 볼지" 비율을 정해 정보를 섞는 것. 거리와 상관없이 한 번에.

2query, key, value와 scaled dot-product attention

알고 싶은 것

"얼마나 볼지" 비율은 어떻게 계산하나?

이 절에 나오는 약자

Q (query)
내가 찾는 것 ("질문").
K (key)
각 token의 이름표. Q와 내적이 크면 잘 맞는다.
V (value)
실제로 가져갈 내용.
d_k
Q, K 벡터의 길이.

예제: token 3개, d_k = 2

1행 한 줄만: 점수 → √2로 나누기 → softmax → value 섞기.

→ 뜻. token 1의 질문 (1, 0)은 key (2, 0)과 가장 잘 맞아 token 1의 value를 가장 많이 (57.6%) 가져온다. 출력은 value들의 가중 평균이다.

기억할 한 줄. softmax(QKᵀ/√d_k)V: 질문과 이름표의 내적 → 비율 → 내용의 가중 평균.

3self-attention과 multi-head attention

알고 싶은 것

Q, K, V는 어디서 오나? 여러 종류의 관계(문법, 가리킴, 바로 앞)를 동시에 보려면?

  • X token마다 한 행 (token 수 × d)
  • W^Q_i, W^K_i, W^V_i head i의 weight, 크기 d × d/h
  • W^O 이어 붙인 결과를 섞는 weight, d × d

말로: 같은 문장 X에서 세 가지 weight로 Q, K, V를 만든다 (self). d를 h조각으로 나눠 head마다 따로 attention을 하고 이어 붙인다. GPT-2 small: d = 768, head 12개 → head마다 64.

예제: GPT-2 small 한 층, 문장이 token 10개일 때

d = 768, h = 12이면 head 하나의 폭은 768 ÷ 12 = 64다. shape를 따라간다.

weight 수를 센다 (bias 빼고).

→ 뜻. 3 × 12 × 768 × 64는 3 × 768 × 768과 같다: head를 12개로 나눠도 weight 수와 계산량은 head 하나일 때와 같다. 대신 12개 head가 서로 다른 관계를 따로 본다. 입력과 출력의 shape(10 × 768)도 같아서 층을 계속 쌓을 수 있다.

결과: GPT-2 small, 같은 문장, head 144개 가운데

→ 뜻. head마다 맡은 일이 다르다: 바로 앞 단어만 보는 head, 가리키는 말을 찾는 head. 많은 head는 볼 것이 없을 때 첫 token에 attention을 몰아 둔다 (attention sink): 사람이 정한 규칙이 아니라 학습에서 생긴 버릇이다.

기억할 한 줄. self-attention = 같은 X에서 Q, K, V. multi-head = 여러 관점을 따로 보고 이어 붙이기.

4positional encoding

알고 싶은 것

attention은 순서를 모른다 (단어를 섞어도 같은 비율). 자리를 어떻게 알려 주나?

  • pos token의 자리 (0부터 센다)
  • PE(pos) 그 자리에 더하는 벡터 전체 (칸 d개)
  • PE(pos, k) 그 벡터의 k번 칸, 숫자 하나 (k = 0 ~ d − 1)
  • i 칸을 둘씩 묶은 번호: 칸 2i는 sin, 칸 2i + 1은 cos

예제: d = 4일 때 자리 0, 1, 2의 PE

d = 4이면 칸은 k = 0, 1, 2, 3이고 묶음은 i = 0(칸 0, 1)과 i = 1(칸 2, 3)이다. 분모는 i = 0일 때 10000⁰ = 1, i = 1일 때 10000^(2/4) = 100이다.

칸 하나 먼저: 자리 1의 칸 2는 묶음 i = 1의 sin이다.

네 칸을 모두 채우면 자리마다 벡터 하나다 (각도는 radian).

거리가 1인 두 쌍(0과 1, 1과 2)의 내적을 비교한다.

→ 뜻. 앞 묶음(칸 0, 1)은 자리가 하나 늘 때 1 radian씩 빨리 돌고(초침), 뒤 묶음(칸 2, 3)은 0.01 radian씩 천천히 돈다(시침). 두 내적이 모두 cos 1 + cos 0.01 = 1.540인 것처럼, PE끼리의 내적은 자리가 아니라 거리에만 따른다. 거리가 2이면 cos 2 + cos 0.02 = 0.584로 작아진다. GPT-2는 이 식 대신 자리마다 벡터를 학습한다: 그래도 가까운 자리끼리 비슷해진다 (cosine 유사도: 자리 10과 11은 0.998, 10과 40은 0.64).

기억할 한 줄. 위치 encoding = token 벡터에 자리 무늬를 더한다. 사인 식이든 학습이든 가까운 자리는 비슷하다.

6encoder, decoder, masking

알고 싶은 것

글을 만들 때는 아직 쓰지 않은 뒷말을 보면 안 된다. 어떻게 막나?

예제: 2절의 Q, K, V로 2행 (token 2는 token 1, 2만 볼 수 있다)

q₂ = (0, 1)과 세 key의 내적을 √2로 나누면 (0, 1.414, 0.707)이다. mask를 더하면 token 3 칸만 −∞가 된다.

→ 뜻. mask가 없으면 2행은 (0.140, 0.576, 0.284)로 아직 오지 않은 token 3도 28% 본다. mask를 켜면 token 3의 몫이 정확히 0이 되고, 앞의 둘이 합 1을 나눠 가진다. 글을 만들 때 뒷말을 미리 보는 반칙이 막힌다.
causal mask

encoder만없음 (모두가 모두를)BERT, ViT이해, 분류
decoder만causal (앞만)GPT, 대부분의 LLM글 만들기

기억할 한 줄. causal mask = 미래 칸을 −∞로 → softmax에서 0. encoder는 다 보고, decoder는 앞만 본다.

8LLM: 다음 token 예측

알고 싶은 것

ChatGPT 같은 LLM은 결국 무엇을 학습한 것인가?

  • x_{t+1} 다음 token
  • h_t 마지막 층이 t번째 token 자리에서 낸 벡터 (GPT-2: 768개)
  • W h_t를 token 종류마다 점수 하나로 바꾸는 matrix (GPT-2: 50,257 × 768)
  • T 온도 (13장 5절과 같다)

token = 글자와 단어 사이의 조각 (BPE). GPT-2의 token 표는 영어 위주라 한국어는 글자 하나가 byte 조각 2~3개(▢)로 쪼개진다: 11글자가 24 token. 한국어용 LLM은 다른 token 표를 쓴다.

→ 뜻. 작은 GPT-2는 문법은 알지만 지식은 약하다 ("Paris"가 5등). 같은 구조를 수천 배 키우고 data를 늘리고, 사람의 피드백으로 다듬은 것이 오늘의 LLM이다. 가장 그럴듯한 것만 이어 붙이면 (greedy): "Deep learning is a very powerful tool for learning about the world around us. It's a tool that can help us".

기억할 한 줄. LLM = causal Transformer를 "다음 token 맞히기"로 아주 많이 학습한 것. 출력은 확률이고, 온도로 고르는 법을 정한다.
