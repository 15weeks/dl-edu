GAN·Diffusion

생성 model

data의 분포를 배워 새 sample을 뽑는 두 방법. 위조범(generator)과 감별사(discriminator)가 겨루는 GAN, 그리고 그림에 noise를 조금씩 더했다가 그것을 거꾸로 지우는 법을 배우는 diffusion. 마지막으로 AI 윤리와 이 뒤에 공부하는 법.

2GAN: generator와 discriminator의 게임

알고 싶은 것

분포를 식으로 쓰지 않고도 그 분포를 흉내 내는 법을 배울 수 있나?

이 절에 나오는 약자

GAN
generative adversarial network. 서로 겨루며 배우는 두 network (Goodfellow 외 2014).
G (generator)
noise z를 받아 가짜 sample을 만드는 위조범.
D (discriminator)
진짜인지 가짜인지 확률을 내는 감별사.

말로: D는 진짜에는 1, 가짜에는 0을 내도록 배우고, G는 D가 가짜에도 1을 내도록 배운다. 둘을 번갈아 한 걸음씩. 끝까지 가면 G의 분포 = data 분포, D(x) = 0.5 (구별 못 함).

진짜 data

결과: 1D GAN, G (1-16-16-1), D (1-32-32-1), 3000번 (PyTorch)

→ 뜻. 봉우리 하나에서는 3000번 뒤 D가 data 자리에서 0.50~0.56으로 거의 평평해졌다: 더 이상 가려내지 못한다. 봉우리 둘은 더 어렵다: 500번에는 평균이 −0.39로 한쪽에 기울었다가, 3000번에는 두 봉우리를 다 덮었다. 다만 모양은 울퉁불퉁하다. 이번에는 없었지만, G가 한 봉우리만 만들고 멈추는 실패(mode collapse)도 GAN에서 흔하다.

기억할 한 줄. GAN = G는 속이고 D는 가려낸다. 겨루다 보면 G의 분포가 data 분포를 닮는다.

3linear GAN과 CNN GAN (MNIST, FMNIST, CIFAR)

알고 싶은 것

그림에도 되나? G와 D를 FFN으로 만들 때와 CNN으로 만들 때 무엇이 다른가?

model
시점
modelGD학습
linear (MNIST)z 64 → 256 → 512 → 784 (FFN)784 → 512 → 256 → 120 epoch
CNN (MNIST, FMNIST)z 64 → 128×7×7 → transpose conv → 64×14×14 → 1×28×28conv 2번 (28 → 14 → 7) → 110 epoch
CNN (CIFAR10)z 100 → 256×4×4 → 128×8×8 → 64×16×16 → 3×32×32conv 3번 → 115 epoch

관찰

→ 뜻. linear GAN은 20 epoch에도 바탕에 점 잡음이 남는다: FFN인 G는 이웃 pixel끼리 비슷해야 한다는 것을 모른다. 5 epoch에는 9·3 같은 비슷한 숫자가 많이 나온다 (mode collapse의 기미). CNN GAN은 10 epoch에 획이 매끈하고 여러 숫자가 고르게 나온다. FMNIST는 셔츠·신발·바지·가방을 알아볼 만하다. CIFAR10은 15 epoch에도 색과 덩어리는 사진 같지만 물체는 알아보기 어렵다: 작은 GAN과 짧은 학습의 한계다.

기억할 한 줄. 그림 GAN은 G에 transpose conv(11장 4절), D에 conv를 쓴다. 학습이 불안정해 Adam β₁ 0.5, LeakyReLU, BatchNorm 같은 요령이 필요하다.

4diffusion의 아이디어: noise를 더하고 되돌리기

알고 싶은 것

그림을 noise로 바꾸기는 쉽다. 거꾸로 noise를 그림으로 바꾸는 법을 배울 수 있다면?

  • √ᾱ_t 원래 그림의 몫 (1 → 0)
  • √(1−ᾱ_t) noise의 몫 (0 → 1)

기억할 한 줄. diffusion = 그림 → noise는 정해진 식으로, noise → 그림은 network로 한 걸음씩 되돌리기.

5forward process와 noise schedule

알고 싶은 것

한 걸음에 noise를 얼마나 더하나? 1000걸음 뒤에는 얼마나 남나?

예제: T = 1000, β가 0.0001에서 0.02까지 곧게 (DDPM, Ho 외 2020)

→ 뜻. t = 500이면 원래 그림의 몫이 √0.0786 = 0.28뿐, 1000이면 0.0064로 사실상 순수한 noise. 곱셈이 쌓이니 한 번에 x_t로 건너뛸 수 있다 (4절 식): 학습할 때 1000걸음을 다 밟지 않아도 된다.

기억할 한 줄. 한 걸음 noise β_t는 작고, 쌓인 결과 ᾱ_t는 1에서 0으로. x_t는 x₀에서 한 번에 만들 수 있다.

6denoising network와 학습 (DDPM loss)

알고 싶은 것

network는 무엇을 맞히도록 배우나?

말로: 그림 x₀와 시간 t를 아무거나 고르고 noise ε를 섞어 x_t를 만든다. network ε_θ는 x_t와 t를 보고 "섞인 noise가 무엇이었나"를 맞힌다. 10장의 denoising autoencoder와 같은 생각을 모든 noise 크기에 대해 한 것.

t = torch.randint(0, T, (B,))                 # 시간 아무거나
eps = torch.randn_like(x0)                    # 섞을 noise
xt = abar[t].sqrt() * x0 + (1 - abar[t]).sqrt() * eps
loss = F.mse_loss(unet(xt, t, c), eps)        # noise를 맞힌다
loss.backward(); opt.step()

이 장의 U-Net: parameter 575,169개, MNIST 60,000장 12 epoch (Apple GPU). t는 14장의 위치 encoding과 같은 사인 벡터로 넣는다.

기억할 한 줄. DDPM 학습 = 섞은 noise ε를 맞히는 회귀 (MSE). 구조는 크기를 줄였다 키우는 U-Net.

7sampling: noise에서 그림으로

알고 싶은 것

학습한 ε_θ로 새 그림은 어떻게 만드나?

말로: 순수한 noise에서 시작해, network가 짐작한 noise를 조금 빼고 약간의 새 noise(z)를 더하기를 1000번. 마지막 걸음에는 z를 더하지 않는다.

기억할 한 줄. sampling = noise에서 시작해 ε_θ로 1000번 조금씩 되돌리기. GAN의 한 번보다 느리지만 안정적이고 다양하다.

8condition, guidance, latent diffusion (Stable Diffusion)

알고 싶은 것

"7을 그려 줘", "고양이 사진"처럼 원하는 것을 그리게 하려면?

  • c 조건 (숫자, 글)
  • w guidance 세기: 조건이 있을 때와 없을 때의 차이를 w배 더 민다
  • ∅ 조건 없음 (학습 때 10%는 class를 지웠다)
guidance w

결과: 숫자마다 50장, 요청한 숫자로 읽힌 비율 (작은 CNN이 판정)

→ 뜻. guidance 없이 조건만 넣어도(w = 0) 90%가 맞지만, 5를 6이나 9처럼 그린 것 같은 실수가 섞인다. w를 키우면 거의 다 맞고, 대신 획이 굵어지고 서로 비슷해진다: 다양함을 내주고 정확함을 얻는다. 판정한 CNN도 시험 정확도 98.0%라 이 비율에 1~2%의 오차가 있다.
latent diffusion (Stable Diffusion v1): 그림 대신 autoencoder(10장)의 latent에서 diffusion
크기숫자 개수
그림512 × 512 × 3786,432
latent64 × 64 × 416,384 (48배 적다)
조건 c글 → CLIP text encoder → token 벡터들, U-Net이 cross-attention(14장 6절)으로 본다–

기억할 한 줄. 조건 c를 함께 넣고, guidance w로 조건을 더 세게 따르게 한다. 큰 그림은 latent에서 diffusion해 계산을 줄인다.
