Overfitting

overfitting, cross-validation, regularization

학습 data에서는 잘 되는데 새 data에서는 안 되는 model. 왜 그런지 보고, data를 나눠서 재는 법(cross-validation)과 막는 법(regularization: λ, dropout, L1·L2)을 그림으로 익힌다.

1overfitting과 일반화

알고 싶은 것

학습 오차가 0에 가까우면 좋은 model인가?

이 절에 나오는 약자

overfitting
(과적합). 학습 data의 잡음까지 외워서 새 data에서 틀리는 것.
underfitting
(과소적합). model이 너무 단순해서 학습 data도 못 맞히는 것.
generalization
(일반화). 처음 보는 data에서도 잘 맞히는 것.
  • E_train 학습 data의 오차
  • E_test 처음 보는 data의 오차
  • 차이가 크면 overfitting

예제: 점 15개에 다항식 맞추기 (시험 점 200개)

→ 뜻. 차수 14는 parameter 15개로 점 15개를 거의 그대로 지나간다(학습 오차 최소). 그런데 점 사이에서 날뛰어 시험 오차가 폭발한다.

해 볼 것

  1. 차수 0 → 3: 두 오차가 함께 준다.
  2. 차수 10 이상: 빨간 곡선이 점 사이에서 튄다. 오른쪽에서 시험 오차(주황)가 하늘로 간다.

기억할 한 줄. 학습 오차만 보면 복잡할수록 좋아 보인다. 처음 보는 data의 오차는 U자를 그린다: 너무 단순하면 underfitting, 너무 복잡하면 overfitting.

2train, dev, test로 나누기

알고 싶은 것

"처음 보는 data"는 어디서 구하나? 설정은 무엇으로 고르나?

이 절에 나오는 약자

dev
development set, validation set (검증 data). 설정을 고를 때 쓴다.
hold-out
학습에 쓰지 않고 따로 떼어 둔 data.

기억할 한 줄. train으로 배우고, dev로 고르고, test는 마지막에 한 번만 본다. 나누기 전에 섞는다.

3k-fold cross-validation

알고 싶은 것

data가 적어서 dev를 크게 떼기 아까우면? 모든 점이 돌아가며 한 번씩 검증을 맡는다.

이 절에 나오는 약자

CV
cross-validation (교차 검증).
k-fold
data를 k 묶음(fold)으로 나눠 k번 학습. 매번 다른 묶음 하나로 검증.
LOO
leave-one-out. k = data 수. 하나씩 빼 보기.
  • k 묶음 수 = 학습 횟수
  • E_val⁽ᶠ⁾ f번째 묶음을 뺀 model의, 그 묶음에서의 오차

예제: 1절의 점 15개, k = 5로 차수 고르기

→ 뜻. 시험 data를 한 번도 보지 않고 고른 차수(5)의 시험 오차 0.125는 가장 좋은 차수(4, 0.093)와 가깝다. 점이 15개뿐이라 k에 따라 고른 답이 조금 흔들린다(k = 3이면 3).

기억할 한 줄. k-fold = k번 학습해서 검증 오차를 평균. data를 아끼면서 설정을 고르는 방법.

5regularization: 복잡함에 벌 주기

알고 싶은 것

복잡한 model을 쓰면서 overfitting을 막을 수는 없나?

이 절에 나오는 약자

regularization
(규제, 정칙화). loss에 "복잡함 벌점"을 더해 model을 얌전하게 만드는 방법들.
λ
lambda. 벌점의 세기.
ridge
weight(계수)의 제곱합을 벌하는 regularization (= L2).
  • L 원래 loss
  • R 벌점 (예: Σ w²)
  • λ 둘 사이의 저울

예제: 1절의 차수 14에 ridge를 더하면

→ 뜻. 같은 차수 14인데 계수를 작게 묶었더니 시험 오차가 차수 3(0.095)만큼 작아졌다. λ도 2~3절처럼 dev나 k-fold로 고른다.

기억할 한 줄. regularization = loss + λ × 벌점. λ가 너무 작으면 overfitting, 너무 크면 underfitting.

6train() mode와 eval() mode

알고 싶은 것

dropout처럼 학습 때만 쓰는 장치는 시험 때 어떻게 끄나?

import torch
torch.manual_seed(0)
drop = torch.nn.Dropout(p=0.5)
x = torch.ones(8)
drop.train(); print(drop(x))   # 학습: 절반을 0, 나머지 ×2
drop.eval();  print(drop(x))   # 평가: 그대로
tensor([0., 0., 2., 0., 0., 0., 2., 2.])
tensor([1., 1., 1., 1., 1., 1., 1., 1.])
model.train()model.eval()
dropout (7절)무작위로 끄고 남은 것 × 1/(1 − p)모두 켬, 그대로
batch normalization (6장)이번 batch의 평균·분산학습 때 모아 둔 평균·분산
언제학습 loop 시작 전dev·test로 잴 때 (with torch.no_grad()와 함께)

기억할 한 줄. 학습 전 model.train(), 평가 전 model.eval(). 바꾸는 것을 잊으면 시험 성적이 흔들린다.

7dropout

알고 싶은 것

학습 때 neuron을 무작위로 끄면 왜 overfitting이 줄어드나?

이 절에 나오는 약자

p
끄는 확률 (dropout rate).
m
mask. 켜면 1, 끄면 0.

말로: 매 step 다른 일부 neuron이 빠진 network로 배운다. 어느 neuron 하나에 기대지 못하니, 여러 neuron이 나눠서 일하게 된다. 1/(1 − p)를 곱해 평균 크기를 맞춘다.

예제: 점 60개(잡음 많음)로 2-24-24-1 network를 500 epoch

→ 뜻. dropout은 학습 성적을 일부러 낮춰 외우기를 막는다. 학습과 시험의 차이가 19%p → 6%p로 준다 (seed 3개 평균).

해 볼 것

  1. 둘 다 학습: 왼쪽은 학습 점을 100% 맞히려고 경계가 학습 점 쪽으로 휘어 들어간다. 오른쪽은 학습 점을 몇 개 틀리는 대신 시험 점수가 더 높다. 진한 점 = 학습 data, 연한 점 = 시험 data.

기억할 한 줄. dropout = 학습 때만 neuron을 확률 p로 끈다. 학습 성적은 조금 내려가고 학습·시험의 차이가 준다.

8L1과 L2 weight regularization

알고 싶은 것

weight에 주는 벌을 |w|로 하느냐 w²로 하느냐가 무엇을 바꾸나?

이 절에 나오는 약자

L1, lasso
|w₁| + |w₂| + … 를 벌한다. 같은 크기의 점들 = 마름모.
L2, ridge
w₁² + w₂² + … 를 벌한다. 같은 크기의 점들 = 원. PyTorch의 weight_decay.
  • L1의 기울기 = λ·sign(w): 작아도 같은 힘으로 0까지 민다
  • L2의 기울기 = λ·w: 작아질수록 힘이 약해져 0 근처에서 멈춘다

예제: 벌이 없을 때의 답 w* = (2, 0.6)

→ 뜻. L1은 덜 중요한 w₂를 정확히 0으로 만든다(λ ≥ 0.34부터). 그래서 L1은 "쓸 feature 고르기"에 쓰인다.

그림 읽는 법

  • 파란 등고선 = 원래 loss L (가운데 w*가 가장 낮다). 초록 = 지금 해와 같은 벌점을 갖는 점들(원, 마름모). 주황 점선 = λ를 0에서 키울 때 해가 지나는 길.

해 볼 것

  1. λ를 천천히 키운다: L1의 해는 마름모 모서리(가로축 위)에 붙어 w₂ = 0이 된다. L2는 원 위에서 둘 다 조금씩 준다.

기억할 한 줄. L2는 모든 weight를 고르게 줄이고, L1은 일부 weight를 정확히 0으로 만든다.
