# DL-Edu: deep learning study pages / 딥러닝 공부 page

Fifteen interactive study pages on deep learning, in English and Korean.
딥러닝을 그림과 직접 움직여 보는 figure로 공부하는 page 15장 (한국어 + English).

- Website / 웹사이트: https://15weeks.github.io/dl-edu/ (Korean / 한국어: https://15weeks.github.io/dl-edu/index-KR.html)
- Source / 원본 파일: https://github.com/15weeks/dl-edu

## Make your own copy / 내 copy 만들기
- Run the code in Colab: press "Open in Colab" in a chapter, then **File → Save a copy in Drive**. Your copy is saved in your own Google Drive; this repository does not change.
- Colab에서 실습: 각 장의 "Open in Colab"을 누른 뒤 **File → Save a copy in Drive**. 내 Google Drive에 copy가 생기고, 이 repository는 바뀌지 않는다.
- Keep the whole site: **Fork** this repository, or **Code → Download ZIP** and open `index.html` (works offline).
- 사이트 전체: 이 repository를 **Fork**하거나 **Code → Download ZIP**으로 받아 `index.html`을 연다 (인터넷 없이도 열린다).
